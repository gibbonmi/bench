# How should exact readers work?

Blocked by: none
Type: Grill

### Question

How should exact readers work?

### Answer

Implement FT125 through the existing coverage, syntax, and response owners.
Return exact file, section, story, or declaration content.
Keep the source identity and continuation position on every page.
Use the existing coverage parser for story rows and Go syntax positions for declarations.

Budget the rendered and escaped response bytes.
Expose a complete continuation route before the help itself can exceed the response budget.
Refuse a changed source identity between pages instead of mixing versions.
Preserve Unicode, control-byte representation, line endings, and empty content explicitly.

Test reconstruction of a complete source from pages through the real command.
Do not add a general text-processing wrapper or a prose summarizer.
Read savings need later session evidence; this map claims none.
