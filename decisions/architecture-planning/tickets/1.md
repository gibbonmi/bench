# How should preflight handle fence and premise knowledge?

Blocked by: none
Type: Grill

### Question

How should preflight handle fence and premise knowledge?

### Answer

Superseded by the 2026-10-17 FT293 decision. A ticket's `Writes:` line is an expectation,
not a complete authorization. Preflight predicts no ownership closure and checks no
charge premises. A need that the gate finds widens a ticket's expected writes inside the
scope that the reviewer approves at spec sign-off. A path outside that scope goes to the
reviewer.

Unknown facts must remain unknown or refused, never guessed green.
