Blocked by: none
Type: Grill

### Question

How should the existing Run name be handled?

### Answer

Preserve the existing error-returning `gittest.Run` contract.
It serves callers that cannot fail a test directly, including goroutines.
The contract is visible at `internal/gittest/gittest.go:275`.

Name the proposed fatal helper `MustRun` in the spec amendment.
Do not replace Run with an incompatible fatal helper.
Keep Output's existing trimmed combined-output behavior.
Keep the proposed raw stdout helper distinct from combined output.

The staged spec incorrectly describes Run as private at line 15.
Its proposed signature at line 82 must change before author dispatch.
This map selects the amendment; it does not edit or approve the successor build.
