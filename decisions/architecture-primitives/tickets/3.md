# Which shell argument spelling should survive?

Blocked by: none
Type: Grill

### Question

Which shell argument spelling should survive?

### Answer

Use the existing sanitize.ShellQuote owner and its always-quoted contract.
Remove independent quote algorithms after their callers migrate.
Avoid a presentation option that creates two quoting policies again.

The current owner handles the empty string explicitly at `internal/sanitize/sanitize.go:109`.
AXI's safe-token loop accepts empty input at `internal/axi/action.go:305`.
That source suggests an empty argument can disappear through direct ShellQuote use.
A focused test must establish its reachable consequence before calling it a reproduced defect.

The selected contract preserves one argument, including an empty argument or an embedded quote.
Callers retain control-byte refusal for line-structured output.
Quoting does not grant command authority or make control bytes suitable for every sink.

The spec must enumerate each changed printed command.
Test argument round trips through a local POSIX shell and exact changed output where it is contractual.
No byte-compatibility result is claimed by this map.
