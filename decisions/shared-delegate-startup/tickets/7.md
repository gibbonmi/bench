# What context should implementation delegates inherit?

Blocked by: #2
Type: Grill

### Question

Which preparation can implementation delegates share across tickets and later batches?

### Answer

Implementation delegates inherit common preparation from a fresh implementation session.
Each delegate receives its ticket assignment after that preparation.
Each author validates its current source and assignment before action.
Later batches refresh changed material.
Repairs stay with the existing author under the retained-author rules.
