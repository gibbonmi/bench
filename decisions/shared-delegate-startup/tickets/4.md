# How does the reviewer activate shared preparation?

Blocked by: #2
Type: Grill

### Question

How does the reviewer activate the optional workflow across phases?

### Answer

One explicit instruction covers an approved delegated run and its reviews.
The workflow adds no Bench CLI command or phase flag.
Standalone phases can receive the same explicit instruction.
This instruction does not itself authorize delegated implementation or change an approved ticket graph.
