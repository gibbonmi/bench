# In what order do the five specs proceed?

Blocked by: #10
Type: Grill

### Question

Which deliverable order best supports the later work and keeps the trial baseline stable?

### Answer

The specs proceed in this order: delegate preparation and review dispatch; diagnostic improvements; landing completion; worktree recovery; delegation trials. Preparation supports subsequent builds, and diagnostics improves their feedback. Trials follow the command folds so they measure work that still requires delegation.
