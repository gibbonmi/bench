# What proceeds after a post-publication failure?

Blocked by: #2
Type: Grill

### Question

When broker refresh fails, may independent cleanup continue before the command reports incomplete effects?

### Answer

If broker refresh fails after publication, the operation stops further mutations. The result reports each effect as complete, failed, or pending. Resume verifies the published commit and continues unfinished effects without publishing again. The worktrees remain while the installation requires repair.
