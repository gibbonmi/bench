# Which effects does landing automate?

Blocked by: none
Type: Grill

### Question

Does landing automatically refresh the broker and clean eligible landed siblings?

### Answer

Landing automatically refreshes the broker and cleans eligible landed siblings. Each effect has a recorded result and an independent resume path. If publication succeeds but broker refresh fails, the result states that publication succeeded and refresh remains incomplete. A retry executes only unfinished effects. Cleanup preserves every worktree whose eligibility cannot be proved.
