# What evidence permits a cheap-tier default?

Blocked by: #4
Type: Grill

### Question

Which comparison and quality criteria must a trial satisfy before the reviewer can change the default route?

### Answer

A trial compares equivalent tasks with pinned inputs and unchanged verification requirements. Total cost includes dispatch, coordinator corrections, return verification, and repairs. A default change requires lower measured total cost without additional missed defects or authority violations. The reviewer approves each default change. A successful trial does not promote itself.
