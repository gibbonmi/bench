# Which path derivation resolves a tree target?

Blocked by: #1
Type: Grill

### Question

`internal/canonicalpath` owns Bench's canonical-path derivation. The gate's
`resolvedPath` helper has no `Abs` step, and a 2026-09-03 Won't handle kept it
as a second derivation. Which derivation resolves a tree target?

### Answer

Tree-target resolution uses `internal/canonicalpath`. The gate's `resolvedPath`
helper becomes a caller of it, so one derivation remains.
