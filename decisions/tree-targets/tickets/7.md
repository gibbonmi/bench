# How is FT341 delivered?

Blocked by: #2, #6
Type: Grill

### Question

FT341 has a clean boundary between the target contract and the migration of
its callers. How many specs does this map feed, and what does each cover?

### Answer

- This map feeds two specs. Spec A lands first.
- Spec A covers the registry scope field, `--in`, target reads, the running executable rule, the response row, and the path derivation. Every tree-scoped leaf accepts `--in` in spec A, because the conformance check requires it of every declared leaf.
- Spec B covers the exec refusal, the end of directory inference, and the migration of every hook and skill.
- A `bench worktree list` filter by spec is out of scope.
