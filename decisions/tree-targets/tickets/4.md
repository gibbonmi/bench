# How does a response name its tree target?

Blocked by: #1
Type: Grill

### Question

Reviews and census entries show callers that graded the wrong tip without
notice. How does a tree-scoped response identify the tree that it read?

### Answer

Each tree-scoped response carries one `tree{target,head,dirty}` row. `target`
is the label or `primary`. `head` is the full HEAD commit. `dirty` states
whether the tree has uncommitted changes. The row prints no pool path.
