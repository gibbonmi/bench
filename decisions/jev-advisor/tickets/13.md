# What does a disabled, failed, or unacceptable Jev result do?

Blocked by: none
Type: Grill

### Question

Which fallback preserves the workstream contract when Jev cannot supply an acceptable result?

### Answer

Accepted choice 2A uses the current workstream model, effort, harness, and bounded task evidence.
Disabled, unavailable, or unacceptable Jev results invoke that fallback. Missing essential evidence or failed fallback causes abstention.

A valid no-match answer remains valid. The choice sets no numeric timeout, budget, or probability threshold.
No silent model substitution is permitted.
