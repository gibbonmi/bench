# Which egress posture does a jev call have?

Blocked by: none
Type: Grill

### Question

jev is a hosted service, so a jev call sends session content to a third
party. `DATA_HANDLING.md` promises that Bench uploads no content. Which
egress posture does the reviewer accept?

### Answer

A jev call occurs only when a committed opt-in and an API key are present.
`BENCH_OFFLINE` suppresses each jev call. A default install makes no jev call
and uploads no content. `DATA_HANDLING.md` gets a fourth egress row when the
first candidate ships. The rejected alternative keeps the integration fully
outside the kit as a harness plugin.
