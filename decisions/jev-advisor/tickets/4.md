# Does the compaction advisor stay in this map?

Blocked by: none
Type: Grill

### Question

The compaction advisor is useful alone, and compact-adviser proves the
mechanism. Does it stay in this map or split off?

### Answer

The compaction advisor stays in this map as the pilot. It supplies the first
replay probe for the other candidates. The rejected alternatives are a
separate map and an install of the upstream plugin with no Bench work. Ticket
#12 still decides whether Bench builds the pilot or adopts the upstream plugin.
