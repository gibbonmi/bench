# What should adopted skill selection do?

Blocked by: none
Type: Grill

### Question

Should adopted skill selection rank suggestions or automatically select additional useful skills?

### Answer

Accepted choice 1A selects additional useful skills automatically after evaluation and adoption.
Explicitly requested and otherwise required skills remain mandatory. A valid empty addition set remains valid.

A missed required trigger is an error even if the working agent later recovers the skill.
The research pass activates no automatic selection.
