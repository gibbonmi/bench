# Which classes does the inventory give a ref, and which classes may the bulk sweep discard?

Blocked by: none
Type: Grill

### Question

`bench worktree clean --discard-branch --unclaimed` discards every unrecorded branch in the two Bench namespaces.
It never calls the landed classifier that the landing prune and `clean --landed` share.
Which classes does the inventory give each ref, and which classes may the bulk sweep discard?

### Answer

The inventory covers every branch under `refs/heads/bench/assign/` and `refs/heads/bench/shift/`.
A branch that an assignment record names classifies as active and stays protected.
An unrecorded branch classifies as landed when the four landed proofs report true: ancestry, the merge check, patch containment, and the reverse-apply proof.
An unrecorded branch classifies as subsumed when its tip equals, or is an ancestor of, a holder's tip.
Every other unrecorded branch classifies as unique.

The bulk sweep discards landed and subsumed rows only, because each of their commits stays reachable after the discard.
A unique row never enters a bulk discard.
