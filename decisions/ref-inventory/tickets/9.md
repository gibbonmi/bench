# What does `bench spec retire` list?

Blocked by: #4, #6
Type: Grill

### Question

An assignment record carries no spec field.
An unrecorded ref carries no label and no request token, so nothing ties it to a slug.
What does `bench spec retire` list, so that a superseded assignment gets a route?

### Answer

The verb lists each active or cleanup-pending assignment whose label or request token contains the slug.
Each line carries the explicit `--target` discard command of ticket 6.
The verb adds one line with the count of unique unrecorded refs and the plan-only unclaimed command.
It discards nothing and changes no exit code.
