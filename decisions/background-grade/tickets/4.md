# What starts a background grade, and in which repositories?

Blocked by: #1
Type: Grill

### Question

Does a Bench verb start a background grade automatically after a lane pass, or does the orchestrator start it?
Which repositories run background grades: the kit only, or also a linked repo?

### Answer

A lane pass starts the background grade automatically, in the kit only.
The reviewer chose this on 2026-10-27.

- `bench commit` and `bench worktree merge` start a background grade after each lane pass that publishes a commit.
- Only a Bench worktree of the kit starts one. The primary checkout never starts one, because it takes no commit.
- A linked repo starts no background grade, because its gate can run any command.
- No guidance step starts a background grade, so each harness gets the same behavior.

A linked-repo opt-in is a parked idea in `capture/IDEAS.md`.
