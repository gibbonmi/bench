# Does a background grade run for a landing that takes the reader set?

Blocked by: #8
Type: Grill

### Question

A reader record authorizes its own landing only and is never reusable green.
So a background grade of a landing subject can only write a whole green.
A whole run costs several times the reader set that it replaces.
Does a lane pass start a background grade when the landing plan of the tip selects the reader set?

### Answer

No. A lane pass starts no background grade when the landing plan of the tip selects the reader set.
The reviewer chose this on 2026-10-27.

- The landing of such a worktree runs its reader set, as it does today.
- A landing plan that selects the whole gate keeps the landing subject of ticket 8.
- A worktree with an open spec build keeps the chunk subject of ticket 8, because a chunk checkpoint never takes the reader set.

So the machine pays no whole run that a shorter reader set would replace.
