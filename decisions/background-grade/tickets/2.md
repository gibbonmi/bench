# What does the resource census under ADR 24 show?

Blocked by: none
Type: Research

### Question

Which workloads run beside a background grade on this host, at which widths, and with which recorded contention?
Which Bench input can select the width of a gate run?

### Answer

The research asset `../assets/research.md` holds the cited facts in its section Q6.

- The host has 16 logical cores and 23 GiB of memory. Its Go configuration sets `-p=4 -parallel=4`, and the profile caps test-running delegates at two.
- The gate gives its children a closed environment, so no ambient `GOFLAGS` reaches them. No Bench setting selects a gate width, so a background width needs a new Bench-owned input.
- The delta schedule entry is a Bench input outside the grade key today, so it is a precedent for that width input.
- The reviewer fixed `-p=2` as the measurement baseline on 2026-10-25, because runners usually have two to four cores.
- The FT255 record holds load-coupled reds, a 2.5 times wall increase beside a gate, and one host crash at full capacity.
- A whole gate takes about 4.3 to 6.5 minutes, and a green stays fresh for 60 minutes.
- No measurement of a background gate beside foreground work exists. The asset names this unknown as U3.
