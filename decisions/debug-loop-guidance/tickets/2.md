# What structure should each phase adopt?

Blocked by: #1
Type: Grill

### Question

Should each phase state its next action, required evidence, next-step condition, and stop condition?
Should debug retain its local instructions while other phases use evidence appropriate to their work?

### Answer

Preserve debug's core instructions in place.
Give spec writing, implementation, and semantic review their own explicit action, evidence, and stop sequence.
Do not extract a universal loop that replaces those local instructions.
Each phase uses evidence appropriate to its work. The project gate remains the oracle.
The reviewer confirmed this option in Round 1 on 2026-09-15.
