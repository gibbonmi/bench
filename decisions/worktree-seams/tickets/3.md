# What happens to a stubbed test whose seam goes?

Blocked by: none
Type: Grill

### Question

The package pins 664 top-level tests, and a removal turns the pin red. When a
test loses the joins seam it replaces, what happens to the test?

### Answer

The test converts to a real fixture and keeps its name. The count pin holds.
The seam reduction deletes no test and merges no test. If a test cannot
convert, the build stops and names the test for a reviewer decision. Ticket 10
pre-decides the four probe-dependent fields: a failed probe keeps the field,
and the build does not stop.
