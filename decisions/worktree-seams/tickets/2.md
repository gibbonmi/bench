# Which predicate keeps a joins seam?

Blocked by: none
Type: Grill

### Question

The joins value has 29 fields. Which predicate decides that a field stays a
joins seam?

### Answer

A field stays a joins seam only when one of two conditions holds. First, it
injects a fault or an interleaving that no real git or temp-directory fixture
produces deterministically. Second, its real default runs a compile or a gate
run. Every other field goes, and its tests use real fixtures.
