# How much of the test tree does the runner spec migrate?

Blocked by: #1
Type: Grill

### Question

The worktree tests hold 196 output-buffer pairs, seven run-wrapper shapes, five
fingerprint extractors, and positional fixture tuples. How much does the verb
runner spec migrate?

### Answer

All of it. The spec deletes the seven run wrappers and the five fingerprint
extractors. Every direct verb call in a test moves onto the verb runner. Each
positional fixture tuple becomes a named fixture value in one helper file. The
count pin holds.
