# Which executable computes the key, runs the phases, and writes the evidence in each run?

Blocked by: none
Type: Research

### Question

Examine a chunk checkpoint and a complete checkpoint in a worktree, a merge, and a landing, in the kit and in a linked repository.
For each run, name the running executable that computes the subject and writes the evidence record.
Name the run binary that runs the gate phases, and the manifest that selects the phases.
Name what the install exception of ADR 16 changes. Cite the owner function for each answer.

### Answer

The asset `decisions/gate-reuse/assets/executable-roles.md` holds the cited answer.
In the kit, each checkpoint and each landing builds its run binary from the graded tree, and the build is reproducible by design.
The landing runs only under the authenticated broker.
A worktree checkpoint runs under the wrapper's selection, which can be the worktree's own candidate build.
The identity root path and the baseline runner identity always differ between a worktree checkpoint and its landing.
