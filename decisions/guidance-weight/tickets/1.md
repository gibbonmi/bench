# Is FT100 one outcome or two?

Blocked by: none
Type: Grill

### Question

FT100 names two surfaces: the always-loaded guidance that every session pays for, and the craft-skill library that loads on demand. Does this map shape one outcome or two?

### Answer

Two outcomes. This map shapes the always-loaded set: `.bench/BENCH.md`, `AGENTS.md`, `CLAUDE.md`, and the skill and phase descriptions that a harness lists on every turn. On Claude Code that set held about 27 KB, or about 6,800 tokens, on 2026-10-11.

The craft-skill library audit is a later outcome with its own map, because its cost, its anchors, and its evidence differ.
