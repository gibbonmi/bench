# Where does the batch-approval rule go?

Blocked by: #5, #2
Type: Grill

### Question

B43 lets a batch approval cover each spec sign-off while the reviewer is unreachable. It acts only at spec sign-off, in `/bench-write-spec` and in craft-tickets. Also, `.agents/commands/bench-drain.md:291` sends the drain's own diff approval to "the batch approval rule". Where does B43 go?

### Answer

B43 moves beside the sign-off stop in `.agents/commands/bench-write-spec.md`, and craft-tickets points there. The line `.agents/commands/bench-drain.md:291` names the drain's own diff approval in its own words, so "batch approval" keeps one meaning.
