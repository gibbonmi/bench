# Which rule places and removes an always-loaded clause?

Blocked by: none
Type: Grill

### Question

FT100 asks each always-loaded clause to cite an observed failure, and FT231 says that no guidance edit comes before its measurement. Which rule decides where a clause lives, and when a clause can go?

### Answer

A clause that acts in every session stays always-loaded. A clause that acts only in some phases moves to a file that each of those phases loads. The move keeps the clause word for word, and its anchors move with it. A move changes no rule, so it needs no FT231 measurement.

A repeated copy of a rule can go now. A rule with no other copy goes only after an FT231 result shows that the rule no longer changes behavior.
