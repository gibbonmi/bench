# Where do the build-orchestration clauses move?

Blocked by: #5, #2
Type: Grill

### Question

The build-orchestration clauses of `.bench/BENCH.md` hold about 3,400 bytes: fresh authors, chunks, chunk review, repair routing, plan expansion, and delegated concurrency. Which file do they move to, so that every phase that acts on them loads them?

### Answer

B11 and B26–B33 move word for word into one new reference file beside the build phase, in `.agents/skills/bench-implement-spec/references/`. That folder already holds `staleness-pass.md`. The 17 lines that point to these rules in `.bench/BENCH.md` point to the new file, and their anchors follow.

`.bench/BENCH.md` keeps a one-line pointer. About 3,450 bytes leave every session.
