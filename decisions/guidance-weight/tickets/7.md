# Does AGENTS.md get a byte budget row?

Blocked by: #3
Type: Grill

### Question

`AGENTS.md` loads in every session in this repo, and no row of the budget table limits it. Does it get a row?

### Answer

Yes. `AGENTS.md` gets an exact row in the budget table. Its limit is its size in bytes after the edits of this outcome, rounded up as #6 sets for every row.
