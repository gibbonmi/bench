# Does the spec amend ADR 0017 and the profile?

Blocked by: #4, #6
Type: Grill

### Question

ADR 0017 states that the landing runs the one whole-project gate and accepts
only a green gate verdict. The profile and the reference also call the whole
gate the one full grade and the landing a full boundary. Does the reopening of
the partition decision cover these statements, and how does the spec record
it?

### Answer

The reopening covers ADR 0017. The spec amends ADR 0017 to state the reader-set
exception for a kit landing inside the reader table. The spec also amends these
statements of the same rule:

- `projects/benchkit.md`: the whole gate as the one full grade, the absence of a
  component partition, and the reduced record classes
- `.bench/BENCH-reference.md`: the landing's prospective execution as a full
  boundary
