# Does the reduced schedule apply only when the graded root is the Bench kit?

Blocked by: none
Type: Grill

### Question

The census maps kit paths to kit test packages. A linked Go repository that
runs the built-in phase table has its own test packages and its own readers.
Does the reduced schedule apply only to the kit, or to every repository that
runs the built-in table?

### Answer

The reader set applies only when the graded root is the Bench kit. A linked
repository always runs its whole phase table.
