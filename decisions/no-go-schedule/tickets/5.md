# Does the reduced schedule run the complete conformance entry?

Blocked by: none
Type: Grill

### Question

The root-conformance entry runs every dev-tier check in about 21 seconds of
test time. If the reduced schedule always runs that whole entry, the census maps
paths to test packages only, and the 22 catch-all checks need no closure. Does
the reduced schedule run the complete entry, or a per-check selection?

### Answer

The reader set always runs the complete root-conformance entry, so every
dev-tier check runs. The reader table maps paths to test packages and phases
only. It maps no path to a conformance check.
