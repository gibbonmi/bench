# Which sources may label an outcome?

Blocked by: none
Type: Grill

### Question

Which sources may write the outcome label that a stated confidence is scored
against, and is a model judgment ever one of them?

### Answer

Three sources may write an outcome label. The gate labels an acceptance row
by its exit. The coordinator labels a done-claim row by a probe of the exact
tree. The reviewer labels a review finding by the disposition recorded in
the review record. No model judgment, native or cross-family, writes a
label.
