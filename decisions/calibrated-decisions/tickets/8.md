# How does the calibration score steer routing?

Blocked by: #7
Type: Grill

### Question

Does the aggregate score change a routing decision under the existing
two-run judgment rule, or does a numeric threshold move a tier on its own?

### Answer

The calibration score is one input to the existing routing rule: change
routing only after two comparable runs, one controlled comparison, or
explicit reviewer direction. No numeric threshold moves a tier in the first
spec. When one model, effort, and role reaches ten scored pairs, the
reviewer decides whether a numeric threshold moves a tier. That decision is
out of this map.
