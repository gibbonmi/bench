# Which landing dogfoods the pairs first?

Blocked by: #10
Type: Task

### Question

Which upcoming landing records the first confidence-and-label pairs, and how
many pairs per role does it yield?

### Answer

The build that lands the calibrated-decisions guidance records the first
pairs. It states a confidence on each of its delegate done-claim rows, each
of its review findings, and its line declaration. Its retro holds the first
calibration table and reports the pair count per role. The retro states the
count; this ticket does not predict it.
