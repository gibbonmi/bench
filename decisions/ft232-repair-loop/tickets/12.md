# What bounds the collection experiment?

Blocked by: #9
Type: Grill

### Question

What sequence count and elapsed time stop the pilot?
What happens when required example classes are absent?

### Answer

Stop the pilot at ten completed repair sequences or fourteen calendar days after activation, whichever occurs first.
The report must cover stalled repairs, productive repairs, unchanged reruns, and overlapping assignments.
If a required example class is absent, report that gap and an inconclusive result.
