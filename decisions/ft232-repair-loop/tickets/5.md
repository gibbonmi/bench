# What evidence permits an advisory specification?

Blocked by: #1
Type: Grill

### Question

Must the experiment distinguish stalled repairs from productive iteration before the advisory receives a specification?
Does an evidence gap require a reviewer decision before collection expands?

### Answer

Before detector specification, the experiment must distinguish stalled repairs from productive iteration in real recorded examples.
The examples must include repeated first failures while useful repairs continue.
If existing records cannot support that distinction, return the evidence gap to the reviewer before collection expands.
