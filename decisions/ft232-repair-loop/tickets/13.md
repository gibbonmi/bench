# What counts as one repair sequence?

Blocked by: #12
Type: Grill

### Question

What starts and ends one sequence, and which repairs belong to it?

### Answer

One repair sequence covers one implementation chunk.
It starts at that chunk's first blocking failure.
It ends when verification closes all its blockers or work stops for reviewer handoff.
The sequence can include several findings and both pre-review and post-review repairs.
A fresh process or review does not create a new sequence.

Report sequences still open at the deadline as incomplete.
