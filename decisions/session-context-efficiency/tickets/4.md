# Which repeated sequences earn one owner-level operation?

Blocked by: none
Type: Grill

### Question

Choose among four preliminary candidates. They are set-wide worktree cleanup,
archive-plus-log preservation, multi-target queries, and build-then-run in one
assigned worktree. Require one user intent, shared invariants, per-target
failures, and a smaller projected result. Leave polling and distinct authority
boundaries separate unless later evidence changes their ranking.

### Answer

The reviewer selects set-wide worktree cleanup and selected multi-target queries for product changes.
A cleanup plan covers the complete selected set with one fingerprint.
The apply operation preserves each target's outcome.
A stale plan refuses before it removes any target and names the re-plan operation.

A multi-target query returns the selected facts for the requested targets through the existing query owner.
It preserves each target's failure and returns less tool-result text than complete child results.
Ticket 8 fixes the selected query families.

Archive and log batches belong in orchestration guidance.
Build-then-run remains a candidate only if further evidence establishes a gap.
Polling and distinct authority boundaries remain separate under the existing exclusions.
