# Does the shaped scope split?

Blocked by: none
Type: Grill

### Question

The shaped scope holds the inventory faces, the result evidence, the
`--changed` cause cell, and the run binary provenance. Only the provenance
waits for research. Does the scope split?

### Answer

The scope splits in two. This map holds the inventory faces, the result
evidence, and the cause cell as one spec. The run binary provenance has its own
map, `decisions/run-binary-provenance.md`.
