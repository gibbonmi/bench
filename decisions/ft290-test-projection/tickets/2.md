# Which identity does the unknown-check refusal name?

Blocked by: none
Type: Grill

### Question

`bench test --check <name>` does a check of the name against the registry in
the executable that runs the verb. This occurs before the run binary selection.
Which identity does the refusal name?

### Answer

The refusal names the path of the running executable and the source commit of
its seal. The running executable owns the check set that the refusal lists. The
refusal does not name the run binary, because no run binary exists at that
point.
