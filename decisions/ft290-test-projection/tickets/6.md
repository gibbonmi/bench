# How does the changed form explain a widened set?

Blocked by: none
Type: Grill

### Question

`bench test --changed` adds the reverse-import closure to the changed packages,
and a Go metadata change selects every package. The output gives no cause. How
does the output explain each selected package?

### Answer

Each packages row of a `--changed` result carries a `selected_by` cell with one
cause. The precedence is `go-metadata`, then `changed`, then `embed`, then
`imports <package>`. For `imports`, the cell names the first selected
dependency in sorted order. A package that changed and also imports a changed
package prints `changed`.
