# What does the fixtures face print?

Blocked by: none
Type: Grill

### Question

What does `bench test --check <name> --fixtures` print, and does it run the
check?

### Answer

The face prints one row for each fixture in the families that the check owns:
the family, the fixture, and the repo-relative path. It runs no test. A check
that owns no family prints an empty table at exit 0. The rows come from the
canary inventory and the registry family binding.
