# Which named checks accept a run pattern?

Blocked by: none
Type: Grill

### Question

`--check` refuses `--run`, so one red in the system suite costs a whole re-run.
Which named checks accept `--run`?

### Answer

`bench test --check system --run <regex>` filters the system suite. A pattern
that matches no test exits 1, as the package form does. Each other named check
keeps the refusal, because it runs through one scoped root test.
