# What does the prose check print on green?

Blocked by: none
Type: Grill

### Question

`bench test --check prose` exits 0 with no output on green. What does a green
result print?

### Answer

A green result prints the `check` row of ticket #3, and the row carries the
count of graded subjects. The result has no packages table, because the prose
check grades no Go package. `--full` lists each graded subject.
