# What proves that the selected check ran?

Blocked by: none
Type: Grill

### Question

A green named-check result does not show that the selected check ran. A green
package is also not distinguishable from a run with no tests. Which predicate
is the proof?

### Answer

Each named-check result carries a `check` row with the check name and a
`tests_run` count. A named check with a `tests_run` count of zero exits 1.
Each packages row also carries a `tests_run` cell.
