# Output ownership and compatibility

Each command domain owns semantic totals, completeness, and empty-state meaning.
Shared projection code renders those facts without deriving them again.
Existing resource-policy owners keep their limits; a renderer does not create a second policy.

An intentional public-output change uses reviewed old-to-new fixtures for the approved delta.
Unchanged behavior keeps its existing exact domain tests.
Bench adds no whole-CLI byte-equality oracle.

Conformance grades the declared inventory and reusable output principles.
Domain tests grade command semantics.
Shared rendering and grammar owners receive focused tests and mutations of their owned facts.
