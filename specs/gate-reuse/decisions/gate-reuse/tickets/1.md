# What does the grade key hold, and what does each verb check apart from it?

Blocked by: none
Type: Grill

### Question

The criterion `FT314-gate-reuse.grade-key` names one grade key "separate from authorization".
The draft frames the run purpose into its key: the checkpoint value, the completion folder, and the source tip.
Today `applyCheckpoint` frames that purpose for a complete checkpoint only.
A chunk checkpoint keeps the base oracle of its subject, because its evidence pass runs on every call.
Decide whether the grade key holds only the verdict inputs.
Decide whether each verb runs its purpose and evidence checks on every call, apart from the key.

### Answer

The grade key frames only the verdict inputs.
These are the tree minus the declared evidence paths, the run binary member, the toolchain, the schedule, and the capability posture.
Ticket #4 decides the evidence paths, and ticket #3 decides the run binary member.
The grade key frames no run purpose: no checkpoint value, no completion folder, and no source tip.

Each verb runs its own purpose and evidence checks on every call, apart from the key, as the chunk checkpoint does today.
So a green of tree T under equal verdict inputs answers a complete checkpoint and a landing of T.
Each of those verbs still runs its completion evidence pass before it accepts the green.

The authorization of a verb is the grade lookup plus that verb's own checks.
This reverses the draft rule that an unpurposed green never answers a completion.
