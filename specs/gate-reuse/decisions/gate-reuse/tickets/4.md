# Which paths are the declared evidence paths?

Blocked by: #1
Type: Grill

### Question

The criterion `FT314-gate-reuse.grade-key` names the tree minus the declared evidence paths.
The FT445 chunk checkpoint key already leaves out the review record of its spec, and the checkpoint grades that record on every call.
Decide the path set and the file that declares it.
Decide which check grades a declared path when the key leaves that path out.

### Answer

The only declared evidence path is the review record of the spec that a chunk checkpoint names.
`reviewrecord.RecordPath` derives that path, as it does today for the FT445 chunk key, so no new declaration file exists.
A verb that names no chunk strips no path from the tree.
The chunk checkpoint grades the stripped record on every call, through its evidence pass and its record prose grade.
A complete checkpoint and a landing grade the full published tree, so every gate reader sees the review record before publication.
