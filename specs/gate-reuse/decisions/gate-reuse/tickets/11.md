# Does the measured saving justify the build, and in which scope?

Blocked by: #7
Type: Grill

### Question

Ticket #7 measures the saving of the grade key before any code change.
FT451 and FT450 depend on the grade key, whatever the saving of FT314 alone is.
Decide whether the spec proceeds with the full scope, narrows, or stops for a commitment change.

### Answer

The spec proceeds with the full scope that tickets #1, #3, #4, #5, and #10 decide.
It adds one behavior: the complete checkpoint runs under the authenticated landing broker, which the landing route selects today.
So a green complete checkpoint answers the landing of the same tree, and the saving approaches the upper bound of about 53 minutes per week.

The complete checkpoint then refuses or goes red on each condition where the landing would.
A declared build already installs its candidate as the broker, so its complete checkpoint runs under that candidate.
The chunk checkpoint keeps the wrapper's selection.
