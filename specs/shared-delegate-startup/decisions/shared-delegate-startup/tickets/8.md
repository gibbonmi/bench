# What context should review delegates inherit?

Blocked by: #2
Type: Grill

### Question

Which shared context preserves independent review derivation?

### Answer

Review delegates inherit neutral preparation containing the frozen diff and primary sources.
That preparation contains no author rationale or other reviewers' findings.
Each axis independently derives its facts and conclusions.
The inherited source material does not replace required independent source checks.

Source: reviewer acceptance of all recommendations in the current conversation, 2026-09-16.
