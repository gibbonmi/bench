# What evidence permits a different model line?

Blocked by: #2
Type: Grill

### Question

Which evidence must establish lower total cost before the optional route changes the selected model line?

### Answer

A documented total-cost estimate permits a different line when the estimated total is lower.
The estimate covers preparation, all delegates, output, and expected repairs.
Unknown required cost inputs retain the existing line.
Actual results remain separate from estimates.
The declared line remains subject to the native inheritance contract.
