# What happens when a suitable fork is unavailable?

Blocked by: #2, #5
Type: Grill

### Question

Which route preserves phase authority when native context inheritance cannot meet the required contract?

### Answer

Build and review phases use fresh delegates with explicit prepared evidence when a suitable fork is unavailable.
The coordinator reports the fallback.
A suitable fork preserves the required context, line, and isolation.
Spec writing retains its mandatory approved-context fork and uses a capable-session handoff if that fork is unavailable.
The fallback does not waive current source checks, review independence, or retained authorship.

Source: reviewer acceptance of all recommendations in the current conversation, 2026-09-16.
