# Which seam forms should the audit admit?

Blocked by: none
Type: Grill

### Question

Which seam forms should the audit admit?

### Answer

Prefer real modules and instance-local collaborators at existing production interfaces.
Admit a fault seam when a named test needs a state that the real dependency cannot produce reliably.
The audit must cover named ports, package variables, setters, setter aliases, and runtime branches.

Each admitted exception names its production owner, consuming tests, failure purpose, and isolation rule.
It must retain production validation and authority checks.
A hook that returns success without exercising those checks is not admissible.

Prefer replacing a global setter with an instance-local seam when that preserves the tested behavior.
A retained global setter requires serial isolation and guaranteed restoration.
A returned restore function alone does not prove either property.

The current derivation inspects named types and their uses at
`internal/conformance/injected_ports_test.go:159`.
Extend that audit rather than adding an unrelated scanner with another policy.
