# What must prove that the policy is enforced?

Blocked by: none
Type: Grill

### Question

What must prove that the policy is enforced?

### Answer

The spec must test the audit's actual production scan.
Add independent cases for an unregistered setter, an alias, a ForTesting variant, and a test-runtime branch.
Each forbidden addition must turn the audit red.
A registered seam must still fail if its consumer or isolation evidence disappears.

Keep negative controls for ordinary functions and source examples.
Use the existing audit's diagnostic and refusal conventions.
Use shared syntax observations only where their lifetime and subject rules fit.
FT365 does not decide which seams are legitimate.

Before a removal ticket, record the exact caller census and replacement failure witness.
For a retained hook, record why a simpler real-dependency test is insufficient.
This map establishes policy; it does not claim that every existing hook already complies.
