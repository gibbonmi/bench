# What do the diagnostic improvements report?

Blocked by: #1, #3
Type: Grill

### Question

Do staged prose checks grade staged bytes, and do diagnostic projections distinguish selected checks from tests that actually ran?

### Answer

The staged prose check grades staged contents, including when working files differ. Long-paragraph diagnostics identify the offending paragraph and its sentence starts. Anchors report source line locations. Probe output distinguishes selected checks from tests that actually ran. No execution cannot appear as successful test evidence. Help describes the actual build and selection behavior without a second implementation of those rules.
