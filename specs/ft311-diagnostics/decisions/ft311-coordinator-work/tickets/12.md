# How do drafts handle missing evidence?

Blocked by: #1, #3
Type: Grill

### Question

What do retrospective and handoff drafts report when source records are missing or disagree?

### Answer

Retrospective and handoff drafts mark missing facts unknown and cite contradictory evidence. Missing timing data does not block a draft. A missing or conflicting revision identity blocks any continuation instruction that depends on it. Drafts invent no attribution and never report completion from an agent claim alone.
