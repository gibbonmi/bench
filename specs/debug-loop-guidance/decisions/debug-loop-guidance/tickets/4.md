# How should ticket slicing apply the structure?

Blocked by: #2
Type: Grill

### Question

Should ticket slicing receive an explicit action, evidence, and stop sequence at its existing owner?

### Answer

Include ticket slicing in the replacement spec, at the existing craft-tickets owner.
Start with the delivered outcome and identify its smallest complete vertical slice.
Name a concrete acceptance scenario and the checks that establish completion while successors remain unbuilt.

Record real dependencies and the value each predecessor supplies.
Use shared writes to determine order, without treating them as automatic grounds to merge tickets.
Split independently useful outcomes. Merge fragments that cannot deliver or verify anything alone.

Keep behavior, tests, and integration together. Do not require implementation during slicing.
The reviewer approved this addition on 2026-09-15 for both candidate specs.
