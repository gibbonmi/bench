# Which test packages read the live tree through a child process?

Blocked by: none
Type: Research

### Question

The Go test log records only the reads of the test process. Which test packages
start a child process, such as `bench`, `git`, or `go`, that reads a record or
guidance path of the live tree? Which phases hold those packages?

### Answer

A denial probe found two readers that the in-process trace does not show. The
[research asset](../assets/research.md) holds the method and the limits as T3.

- `internal/releaseevidence`, in the `test` phase. Its test runs
  `scripts/build-release-evidence.mjs` through `node`, and the script copies
  `CHANGELOG.md`.
- The `system` phase. Its `bench setup --yes` and `link` journeys read guidance
  through a `bench` child. Its candidate-install journeys copy
  `.bench/commitment.json` in process, under the `system` build tag.

With every covered file unreadable, 28 system tests failed. With only the
record files unreadable, 3 system tests failed. The system phase therefore
reads both families. No other test package gained a failing test.
