# What bounds a run of reduced landings before a whole run?

Blocked by: #6
Type: Grill

### Question

Each reduced landing trusts the last whole green. Which bound forces the next
landing to run the whole gate: a count of reduced landings, an age, or both?
Which value does the bound take?

### Answer

A landing runs the whole gate instead of the reader set in each of these cases:

- Five landings with a reader record already follow the green marker on the
  destination.
- A first-parent commit after the green marker, up to the destination, has no
  reader record of its own tree.
- A whole verdict on a landing to this destination since the green marker is
  red.
- The oracle identity differs from the identity of the last whole green.

Otherwise, a landing inside the reader table runs the reader set.

The oracle identity is the gate subject identity without the tree, plus the
`BENCH_REQUIRE_CAPABILITIES` posture. The subject identity holds the policy
version, the launcher closure, and the declared environment, paths, and tools,
which include `go` and `node`. One function computes it, and the `oracle` digest
of the full verdict adds the tree to that same computation.

Each commit therefore keeps its own reader record. Only the file layout of the
records is spec-writer discretion.
