# Which gate entry points run the reduced schedule?

Blocked by: none
Type: Grill

### Question

The landing runs the whole-project gate on the prospective landing tree. A
plain `bench gate`, a `bench worktree merge`, and a chunk or complete checkpoint
also run the gate. Which of these entry points run the reduced schedule when
the change is inside the census?

### Answer

Only `bench worktree land` runs the reader set. A plain `bench gate`,
`bench gate --fresh`, `bench worktree merge`, and the chunk and complete
checkpoints keep their current schedules.
