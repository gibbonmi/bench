# Which changed paths force the whole gate, and which phases does the reader set run?

Blocked by: #5, #7, #11
Type: Grill

### Question

A test log never shows a compile-time embed, the shellcheck inventory, or a
change to a Git mode. The `race` phase also requires every sentinel of its
table. Which changed paths send a covered landing to the whole gate whatever
the table says, and which phases does the reader set run?

### Answer

A covered landing runs the whole gate when a changed path is in any of these
sets:

- the embed targets of the composed tree
- the shellcheck inventory
- the paths whose old or new Git mode is a symbolic link or a gitlink

Otherwise, the reader set runs these phases:

- the complete root-conformance entry
- the readers that the derived table names for a changed family
- the declared child readers for a changed family
- the `system` phase
- the `race` phase with its whole table, when a race-table package reads a
  changed family

The reader set runs no `gofmt`, no `vet`, and no `shellcheck`.
