# One spec or two?

Blocked by: #5, #6, #9
Type: Grill

### Question

Chunk A is the classifier, the plan rows, and the status route.
Chunk B is the discarded ref, the `--target` extension, and the retire listing.
Do the two behaviors ship as one spec or two?

### Answer

One spec ships both behaviors as two implementation chunks, A before B.
Chunk A alone makes the sweep safe for the subsumed refs.
Chunk B alone would guard nothing, because no class exists before A.
One spec keeps the fingerprint and the row schema single-sourced across both chunks.
