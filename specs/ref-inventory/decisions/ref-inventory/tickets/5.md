# What does the status git row route to while unclaimed refs exist?

Blocked by: #1
Type: Grill

### Question

The status git row routes to `bench worktree clean --discard-branch --unclaimed --apply-current` when the unclaimed count is above zero.
That route discards cited evidence with no reviewer look.
What does the row route to?

### Answer

The status git row counts the landed, subsumed, and unique refs.
It routes to `bench worktree clean --discard-branch --unclaimed` with no apply flag, always.
The plan output alone names the apply command, and only when a landed or subsumed row exists.
`bench status` never names a destructive command.
