# How does the reviewer discard one unique unrecorded ref?

Blocked by: #1, #3
Type: Grill

### Question

The explicit forms of `clean` resolve an assignment record.
An unrecorded ref has no record, so no explicit route reaches it today.
How does the reviewer discard one unique unrecorded ref?

### Answer

`bench worktree clean --discard-branch --target <selector>` resolves an unrecorded Bench-namespace branch.
The selector is the assignment id segment of the branch path, or the branch path itself.
The set plan shows the class `unique` and the discarded ref it plans to write.
The apply needs the set fingerprint.
The fingerprint binds each row's class, so a class change between plan and apply refuses as stale.

Inside the transaction, the discarded ref is written before the exact-object branch delete.
The preserve step and the discard step never split across two commands.
