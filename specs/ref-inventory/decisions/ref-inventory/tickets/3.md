# What is a discarded ref, and how long does it live?

Blocked by: #1
Type: Grill

### Question

The recovery namespace `refs/bench/recovery/` is keyed to an assignment record, and the session-start sweep empties it.
An unrecorded ref has no record, so nothing can hold its work through a discard today.
What preserves a discarded unique ref, and how long does it live?

### Answer

A discard of a unique ref writes `refs/bench/discarded/<yyyymmdd>/<branch-path>` at the exact tip it deletes.
The write happens in the same transaction as the delete, and before it.
The outcome row names the discarded ref.

The session-start sweep removes a discarded ref 30 days after the date in its path and reports the count.
The lifecycle-namespace emptying rule does not apply to the discarded namespace.
