## What to build

`internal/axi/compatibility` derives the root half of the compatibility case index
by parsing the `commandRegistry` literal in `cmd/bench/main.go` with `go/ast`, and
`cmd/bench/axi_compatibility_test.go` — which lives in package `main` and can read
the real `commandRegistry` value — asserts that the derived census and the live
registry are the same set of `{name, attachment}` pairs in the same order.

Membership is derived, never listed by hand: the census must contain all 48
registry roots, from `anchors` through `release`, each carrying the attachment
class the registry declares (empty for the in-process `outputCommand` roots, then
`attachmentDirect`, `attachmentSystem`, and `attachmentShip`). `bench commands
--brief` is not a derivation source — it prints three hard-coded names — and the
RM1/derivation-source row keeps that closed.

Each derived root lands in the case index under the stable case ID `root-<name>`,
so the later argv-class and comparison tickets attach classes to a member that is
already proven complete.

## Acceptance

- [ ] [RM1] (covers CO3) the derived root census contains every `commandRegistry` entry with its declared attachment, in registry declaration order, and names any member the live registry declares but the census omits.
