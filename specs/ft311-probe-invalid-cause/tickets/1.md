## What to build

Report a zero-match mutation as an invalid probe verdict with cause `substring-miss`.
Keep the existing build-failed cause for a mutant that does not compile.

## Acceptance

- [ ] A zero-match swap, omit, or unwrap prints a probe row with cause `substring-miss`.
- [ ] A substring miss reports zero failed tests and restoration state `untouched` without a tree write or test run.
- [ ] A mutation that does not compile remains invalid with cause `build-failed`.
- [ ] A mutation with more than one match keeps the existing ambiguous-mutation refusal.
