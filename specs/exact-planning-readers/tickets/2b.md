## What to build

Deliver `bench spec show <slug-or-path> --story <positive>` and `--section coverage`.
Coverage exposes `Describe(content []byte) (Document, error)` over its one private parse in rows.go.
The document carries an ordered Story projection and typed CoverageRow values with original byte spans.
Keep original byte offsets apart from the normalized cells that validation uses.

One versioned coverage-owned serialization carries a story's exact text, its matching rows in authored order, explicit seam cells, and source spans.
The root adapter in planning_reads.go composes spec and coverage; spec does not import coverage.
Repeated selected story numbers refuse as ambiguous without a change to the existing coverage Check.
Keep rows.go within 400 lines; split coverage.go only when growth requires it.
rows.go takes the User stories title from `spec.StoriesSection` instead of its own literal.

Every absent selection, including an absent section, stories section, status, or story, is a page with present false from the page owner, not a separate record.
For a valid UTF-8 selection, the page owner refuses a cursor offset inside a rune as an invalid cursor.
`spec show` takes no `--in`, as the spec grammar shows, so a leading `--in` refuses as usage.

## Acceptance

- [ ] The coverage shortcut returns the authoritative accepted-map span, including its heading and table.
- [ ] A numbered story returns its exact authored text and every matching typed row in authored order, with identifier, story IDs, behavior, seam, rationale, and span.
- [ ] A malformed map or a repeated selected story number refuses before content; existing Check behavior does not change.
- [ ] A valid absent story returns present false and empty row arrays, and every other absent selection is also a present-false page.
- [ ] A cursor inside a rune of a valid UTF-8 selection refuses before content, and an invalid UTF-8 selection keeps its byte cursor.
- [ ] `spec show` with `--in` refuses as usage.
- [ ] Planned TestExactStoryProjection grades the coverage owner, and TestExactReaderCLIReconstruction reconstructs a multi-page typed story payload.
