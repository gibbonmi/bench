## What to build

Deliver `bench outline [path] --symbol <name-or-receiver.method> [--production|--test]` through Go syntax positions and ER-C1's page owner.
Parse comments and slice original source bytes from the attached Doc group through the declaration End; a grouped declaration is one selection.
Receiver-qualified names distinguish pointer and generic methods.
Candidates order by file, source offset, and qualified name; an ambiguous result names each file and an executable narrowing route.

`--symbol` with `--full` is a usage refusal, and a syntax error refuses before paging.
Reuse `bounds.OutlineFileLimit` and the existing tracked Go scope.
The outline row becomes an approved query, and `internal/outline` joins the command packages.
The usage pins in outline_filter_test.go change in place.

## Acceptance

- [ ] Functions, methods, types, constants, variables, and grouped declarations reconstruct their complete original spans, including attached documentation.
- [ ] Adjacent declarations and unattached comments stay outside the span.
- [ ] Receiver qualification, explicit files, and production or test filters narrow candidates; ambiguity returns candidates and no body.
- [ ] An absent symbol returns explicit absence, malformed Go refuses, and `--full --symbol` refuses as usage.
- [ ] Planned TestDeclarationSpans and TestDeclarationSelection grade the owner, and TestExactReaderCLIReconstruction reconstructs a multi-page declaration.
- [ ] Existing outline metadata, counts, and filters keep their result tables, and each legacy form gains derived AXI continuation help.
