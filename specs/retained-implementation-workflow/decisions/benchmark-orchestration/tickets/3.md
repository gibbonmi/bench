# Does uncapped continuation extend beyond this benchmark?

Blocked by: none
Type: Grill

### Question

Does uncapped continuation extend beyond this benchmark?

### Answer

Uncapped continuation becomes an explicit supported policy. Work continues within approved scope while it makes progress. A required reviewer decision, external blocker, or explicit user budget stops the run. Repeated failure to advance triggers reassessment instead of another identical attempt.

Reviewer confirmed this decision in the shaping conversation.

Scope clarification confirmed on 2026-09-11: uncapped continuation applies only to the retained implementation session. The separate bench shift runner and its limits remain unchanged.
