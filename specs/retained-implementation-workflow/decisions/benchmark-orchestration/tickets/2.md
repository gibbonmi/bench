# Does retained authorship become the default?

Blocked by: none
Type: Grill

### Question

Does retained authorship become the default?

### Answer

Implementation stays in one model session by default, across tickets and repairs. That session owns coding, tests, required probes, and implementation repairs; it does not delegate implementation. Each ticket keeps its verification and commit checkpoint. Independent Standards, Spec, and Coverage reviews use subagents. Ticket #6 defines the exception for brief diagnostic consultation.

Explicit reviewer instructions can override this default. This decision does not fix a model or effort level.

Further measurement is not a prerequisite for adopting this default.

Reviewer confirmed this decision in the shaping conversation.
