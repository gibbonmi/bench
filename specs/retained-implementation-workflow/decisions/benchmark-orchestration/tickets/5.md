# What write authority and gate expansion can the implementation session use?

Blocked by: #2
Type: Grill

### Question

What write authority and gate expansion can the implementation session use?

### Answer

The approved spec defines the implementation session's overall write authority. Chunk file lists describe expected changes for planning and review. They do not create another permission boundary.

Models have standing approval to expand file authority and gate coverage when needed to implement the approved spec. Update the affected spec or ticket record before relying on the expansion. Preserve existing checks, pass criteria, and required behavior. This approval does not authorize unrelated product scope.

Record each chunk-boundary change, write-authority expansion, or gate expansion through `bench learning`. State what changed, why it was needed, and the applicable verification evidence. The drain reviews these entries after the work. Do not pause for another approval of an expansion covered by this policy.

Reviewer confirmed this decision in the shaping conversation.
