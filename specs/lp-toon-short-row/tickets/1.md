# Return an error from the TOON encoder on a short row

Blocked by: none
Writes: internal/toon/toon.go, internal/toon/toon_test.go
Covers: none

## What to build

`table` in `internal/toon/toon.go` indexes `row[j]` for every field, so a row with fewer cells than fields panics with an index out of range. A command that builds a row by hand then crashes instead of printing the AXI error line.

Make `table` return an error when a row's cell count differs from the field count. The error names the row index, the cell count, and the field count. `Table` and `TableTyped` share the check because both call `table`. Keep `RenderError` as it is. Do not widen its kind label, because a short row is a caller defect and not an unrepresentable cell. Do not touch any caller.

Line: opus / medium, two implementation iterations.
Self-probe: remove the length check and report the observed panic in the new test. Restore the check after the probe.

## Acceptance

- [ ] `Table` and `TableTyped` return a non-nil error, and no panic, for a row shorter than the field list. The same holds for a longer row.
- [ ] The error text names the row index, the cell count, and the field count.
- [ ] `go test ./internal/toon/` is green with no test edited to pass, and the existing escaping and empty-table tests do not change.
- [ ] Return the exact tip, the changed paths, the self-probe result, and the remaining limitations.
