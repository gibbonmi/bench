# How does a caller name the tree target?

Blocked by: none
Type: Grill

### Question

Today the wrapper and 55 Go call sites derive the tree from the current
directory. What does a tree-scoped verb accept as its tree target, where does
the flag sit, and what happens when the caller gives none?

### Answer

- `--in` accepts a worktree label or the keyword `primary`, and nothing else. A path operand exits 2.
- `--in` follows the verb leaf, as in `bench gate --in <label>`. A repository-scoped leaf that gets `--in` exits 2.
- With no `--in`, a tree-scoped verb targets the primary checkout of the current repository. After spec B lands, this holds even when the current directory is inside a pool worktree. Ticket 6 owns the transition.
- No environment variable selects a tree target.
