# What may reset discard?

Blocked by: #1
Type: Grill

### Question

Which recovery point does reset restore, and what must it preserve before it changes the checkout?

### Answer

Reset restores an explicitly named checkpoint from the assignment history. Before reset, it preserves every affected staged, unstaged, and untracked change and provides an exact restore command. Apply requires the approved plan fingerprint. A changed checkout causes refusal. Reset never infers the checkpoint from the latest main.
