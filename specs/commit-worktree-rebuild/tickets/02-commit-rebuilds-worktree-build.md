## What to build

After a `bench commit` publishes in a kit worktree, the commit makes the worktree's `dist/bench` match the tree before the background grade starts. The spec section "The commit step" states the rule, its order, and its two output lines. This ticket consumes the two owners of ticket 01: `freshness.DiffChangesBuildInputs` decides whether the diff names a build input, and `freshness.Refresh` runs the seal check, the build, and the second seal read.

`internal/commit/background.go` gets the package variable `worktreeBuild`, which holds `runbinary.BuildSubject`, and the internal form `refreshWorktreeBuild(root, published, home string, build func(context.Context, string, string) error, stderr io.Writer)`, which reads no ambient value. `commit.Run` (`internal/commit/commit.go:81-110`) calls `refreshWorktreeBuild(root, outcome.Published, benchhome.Dir(), worktreeBuild, stderr)` only when `exit` is 0 and `outcome.Published` is not empty, and before `startBackgroundGrade` at `commit.go:108`.

`refreshWorktreeBuild` skips silently when `freshness.DeclaresBuildInputs(root)` is false. It skips silently when `os.Lstat(freshness.PublishedExecutable(root))` reports `fs.ErrNotExist` and `freshness.DiffChangesBuildInputs(root, published+"^", published)` is false. Any other `Lstat` answer counts as present. It then calls `freshness.Refresh(context.Background(), root, build)`. It prints nothing when no build ran. It prints `worktree build: rebuilt dist/bench` on stderr when `Refresh` reports `rebuilt`, even when `buildErr` is not nil. It prints one stderr line `worktree build: failed: <cause>; rebuild with <remedy>` when `Refresh` reports a non-nil `err`. The cause is `buildErr.Error()` when `buildErr` is not nil. Otherwise it is `Refusal.Reason()` when `errors.As` finds a `*freshness.Refusal` in `err`, and `err.Error()` for any other error. The cause passes through `sanitize.Controls`. The remedy is `freshness.RebuildIn(home, root).Action`. The step never changes the commit exit, and it writes nothing on stdout, so `committed{published_commit=…,path_count=…}` stays the last stdout line. It reads no held-install predicate. Add no literal that holds `next=`, `next[`, `run bench `, or `"; then "` in `internal/commit` (`internal/conformance/registry/route_bypass.go:16-27`).
