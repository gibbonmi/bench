# What encoded response budget must the charge enforce?

Blocked by: #3
Type: Grill

### Question

Should every response stay within 48,000 encoded stdout bytes, including metadata, errors, and next actions?
The recommendation leaves margin below the reproduced 60,000-byte ceiling.

### Answer

Each preparation, retrieval, verification, cleanup, and error response contains at most 48,000 encoded stdout bytes.
The limit includes metadata, source bodies, escaped values, and next actions.
No ticket, source descriptor, inventory, or diagnostic receives an unbounded exemption.
