# Must review captures reproduce across different environments?

Blocked by: #3
Type: Grill

### Question

Should this change freeze exact review output and record collector provenance without adding reproducible execution across machines?
The consumer loader inherits the local Go environment through its package configuration.
See `internal/consumers/loader.go:25` and `internal/preflight/review.go:50`.
A Git pair alone does not close every generated-input dependency.
The recommendation preserves each exact capture and changes its identity when generated bytes or declared provenance change.
A new hermetic collector contract would expand the observable scope.

### Answer

The change freezes exact generated review bytes and records collector provenance.
Changed generated bytes or declared provenance produce a changed evidence identity.
Identical complete logical inputs and bytes produce the same identity.
The change does not require reproducible collector execution across machines.
A Git pair alone does not establish identical complete collector inputs.
