# What artifact capacity and cleanup limits should Bench own?

Blocked by: #7
Type: Grill

### Question

Which measured artifact and total-store limits should the evidence owner enforce?
The proposal uses explicit cleanup with reader and writer exclusion.
Capacity refusal must preserve existing evidence and name a deterministic recovery action.

### Answer

The default repository quota is 1 GiB.
The quota includes published artifacts and temporary writes.
The owner sets no smaller per-artifact limit.
Preparation permits an explicit quota override for larger required evidence.
Capacity refusal preserves existing evidence and names cleanup or an explicit larger quota as recovery.
The default is an operational policy, not a limit established by the prototype timings.

The owner performs no automatic eviction.
Cleanup provides a bounded plan of exact targets before an explicit apply operation.
The apply operation revalidates the plan fingerprint.
Cleanup excludes active readers and writers.
Explicit cleanup can invalidate idle handles, and later retrieval must refuse rather than substitute evidence.
Interrupted temporary files can enter the plan only after the owner establishes that no active writer owns them.
