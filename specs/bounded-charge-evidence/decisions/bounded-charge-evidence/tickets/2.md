# What must charge completeness prove before action?

Blocked by: none
Type: Grill

### Question

Must all required source bytes appear in one CLI response?

### Answer

The reviewer separates evidence completeness from response completeness on 2026-09-15.
All required pinned evidence must be verified and available to the consumer before action.
Several bounded responses can deliver that evidence.
Each response must state its own completeness and the remaining retrieval action.
Approval and the task-specific supplement remain separate prerequisites.
The CLI must not infer either prerequisite from a complete evidence set.
