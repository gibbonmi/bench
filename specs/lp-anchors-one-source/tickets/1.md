# Single-source the anchors transforms with the evaluator

Blocked by: none
Writes: internal/anchors/locate.go, internal/anchors/match.go, internal/anchors/registry.go, internal/anchors/locate_test.go, internal/anchors/match_test.go
Covers: none

## What to build

The anchors package holds two derivations of three transforms. `StripHTMLComments`, `MarkdownH2Sections`, and `CollapseSpace` serve the evaluator. `stripCommentsMapped`, `sectionRunesMapped`, and `collapseSpaceMapped` serve `Locate`. The `Locate` doc comment promises that the two stay in lock step, but nothing enforces it.

Make the mapped transform the one source of each rule. Derive the evaluator's string form from the mapped form. Strip, collapse, and section resolution each run once, over runes with an origin map. The string form is the projection of the mapped output. `sectionRunesMapped` computes its own owning-heading count instead of a call into `MarkdownH2Sections`, so the count and the body come from one walk. Keep every exported name and signature, because `internal/anchors/registry.go` and `internal/canary/mutation.go` call them.

Keep the observed behavior byte-identical for every existing test in the package. A section body from the string form keeps its current join shape. An unterminated comment truncates. A comment that the removal itself creates hides its needle in both forms.

Line: opus / medium, two implementation iterations.
Self-probe: remove the restart loop from the one shared comment strip, so a rejoined comment survives. Report the observed red in `TestLocateStripsRejoinedComments` and in `TestStripHTMLComments`. If one of the two stays green, add the row that turns it red.
