## What to build

`inventoryIgnored` in `internal/worktree/subshell.go` keeps every authority-bearing step exactly as it is — the full `git ls-files --others --ignored` enumeration, `sort.Strings(paths)`, the `cleanupOutputSafe` control-byte refusal, the escaping-path refusal, the `ignoredLstat` stat-race refusal, the `ignoredEntryLimit`/`ignoredByteLimit` ceilings, and the `fingerprintParts(name, mode, size)` preimage — and only afterwards hands the already-authorized inventory to the shared `internal/axi` bounded-projection carrier to select the visible entries: 20 by default and `ignoredEntryLimit` (1000) under `--full`. `Shown`, `Truncated`, `AtLeast`, `Summary()`, and the `ignored_paths` preview in `classifier.go` all read from that projection, and no projection happens before the digest is computed.

Tree condition at refresh time: the package directory `internal/axi` exists and exports `axi.Projection`, the CR3 carrier holding selected content plus owner-supplied total, emitted, omitted, truncated, completeness, and counting unit without inferring any of them (the symbol name is fixed by the carriers spec). Confirm with `go doc ./internal/axi Projection` before starting; if the package or symbol is absent, stop and report rather than inventing a local shim.

The safety/fingerprint half and the display half stay in one ticket because a split that lands the display projection first would project a not-yet-authorized inventory, and the ordering red this ticket owns (WI1/route-default's before-fingerprint check) is exactly the invariant such a split strands: neither half can assert it alone.

## Acceptance

- [ ] [WI1] (covers BP3) the ignored inventory stays completely sorted, safety-checked, fingerprinted, and ceiling-bounded before the shared `internal/axi` projection selects 20 default or 1000 full visible entries.
