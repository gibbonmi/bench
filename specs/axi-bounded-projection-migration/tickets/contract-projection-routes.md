## What to build

One conformance census in `internal/conformance` derives the complete set of shared bounded-projection consumers from the four production owner packages, requires it to be exactly the four helper-census owners with their declared per-owner policy (code points capped at 120 for `internal/sanitize`; bytes capped at 4096 with a UTF-8 backoff and an uncapped full mode for `internal/roadmap`; entries capped at 20 default and 1000 full for `internal/worktree`; rows capped at `bounds.OutlineRowLimit` default and uncapped full for `internal/outline`), refuses any consumer it did not declare, and requires zero surviving occurrences of each superseded local selector: `runes = runes[:120]` in `internal/sanitize/sanitize.go`, the `[]byte(s)[:contextBodyLimit]` selection in `internal/roadmap/context_types.go`, the `show := 20` / `inventory.Shown = show` block in `internal/worktree/subshell.go`, and `rows = rows[:emitted]` in `internal/outline/outline.go`. The same ticket updates the census advertisement in `projects/benchkit.md`, because that file restates the owner count this census now derives.

Tree conditions at refresh time: `internal/axi` exists and exports `axi.Projection`, the CR3 carrier whose name is fixed by the carriers spec (`go doc ./internal/axi Projection`); `internal/axi/compatibility` and `cmd/bench/axi_compatibility_test.go` exist and the oracle's frozen baseline manifest for pinned subject `974020e4af8de5ed75098c4c5934a8907952bb2b` carries the derived cases for the four owners' commands (`go doc ./internal/axi/compatibility` and `ls cmd/bench/axi_compatibility_test.go`). If either is absent, stop and report rather than authoring a local golden.

The four owners stay in one contraction ticket because the census asserts exactly four declared routes at once: a per-owner split lands a census that names four owners while one owner's local selector still exists, which is the `TestBoundedProjectionResidueCensus` red no per-owner cut can land green through.
