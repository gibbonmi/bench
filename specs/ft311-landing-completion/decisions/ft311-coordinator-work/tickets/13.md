# What happens when native review dispatch is unavailable?

Blocked by: #6
Type: Grill

### Question

Does review preparation provide manual native charges or use a same-family CLI fallback?

### Answer

When native review dispatch is unavailable, preparation preserves the charges and stops automatic dispatch. It provides an actionable handoff to a capable harness. It never silently substitutes a same-family CLI or collapses independent review axes into the coordinator.
