## What to build

Add `--state-file <path>` to the handoff grammar, beside `--harness` and `--next`.
Without the flag the command reads the document's State and puts it back unchanged, as today.
With the flag the owned section's State body is the file's bytes, and every other field stays derived.

Classify the file before the read, through `bounds.ClassifyNoFollow`, never `bounds.Classify`.
The following form resolves a live link, so it would read bytes outside the named file.
`FileState.Failed()` covers only the unreadable, wrong-type, and malformed states, so key the refusal on those and on `StateAbsent` explicitly.
An absent file, a symbolic link, a special file, and an unreadable file each answer a structured refusal at exit 1.
A file over the record limit answers the same refusal.
`StateEmpty` is not a refusal; it falls through to the empty-State case below.

Refuse a byte the document cannot carry, through the predicate the derived fields already use, widened to the State body.
Refuse a line that would open a section heading, because the next run must still parse the document.

Run the existing State scan over the new body.
An off-ancestry pin, a pin that is not a commit, and an ambiguous abbreviated sha each keep their current fault.
Each also keeps its repair instruction.
Raise every refusal before the document renders, so a refused run leaves the bytes it read.

An empty file writes an empty State, and the header then carries the scaffold guidance again.
Trim the file's trailing newline once, the way the document's own writer trims it.
Change the registry help suffix in place, because `cmd/bench/main.go` is over the line budget.
The conformance tests and the canary fixture are named for closure only, and this ticket does not edit them.

`internal/handoff/state_scan_test.go` is over the line budget, so move its shared fixture helper into the new test file in the same commit.

Line: gpt-5.6-terra / medium, two implementation iterations.
Self-probe an omission of the section-heading refusal and report the observed red on the second parse.
The coordinator independently swaps the classifier call for a plain read at another site.
