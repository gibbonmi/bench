# What proves preservation across the modes?

Blocked by: none
Type: Grill

### Question

What proves preservation across the modes?

### Answer

The spec must retain command-level tests for all four modes.
Cover empty sets, retained members, first failure, later failure, and stale selection.
Use a set with multiple removable and retained members.
One-member fixtures cannot prove order or unreached outcomes.

Preserve the all-row preflight and late-drift witnesses in
`internal/worktree/clean_set_apply_test.go`.
Preserve partial and unstarted results in
`internal/worktree/clean_set_outcomes_test.go`.

Central fault tables may replace repeated mechanism setup.
They cannot replace proof that each mode selects the correct authority and output adapter.
Demonstrate a red when a mode skips its requalification.
