# Should all modes return identical failure rows?

Blocked by: none
Type: Grill

### Question

Should all modes return identical failure rows?

### Answer

Preserve the existing difference.
The unclaimed mode returns the completed prefix and the failed row after a deletion error.
See `internal/worktree/clean_unclaimed.go:215`.
The landed mode also appends unreached outcomes.
See `internal/worktree/clean_landed.go:365`.

The roadmap's claim that every mode already reports unreached members is stale.
Correct that premise in the spec.
Do not change output merely to simplify the shared traversal.

A later proposal may unify these results through a separate behavior decision.
That proposal does not block this preserving refactor.
