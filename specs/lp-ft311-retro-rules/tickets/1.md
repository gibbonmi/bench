## What to build

The `ft311-diagnostics` retro and its three learnings produced four rules. Each rule goes into the budget-free reference file of the skill that owns the moment, as one list item in the section named below. Do not edit a `SKILL.md`, because `bench-craft-tickets/SKILL.md` sits one line under its prose budget and the reference files carry the rules.

In `map-discipline.md`, under `## Before the map locks`, add one item. Each implementation-decision sentence that names a state, a kind, or a condition cites the row and the fixture that reach it. An enumerated kind list takes one row per kind. The evidence is a spec round that missed four red-capable gaps. Two of five baseline kinds had no case, and three named states had no fixture.

In `map-discipline.md`, under `## At ticket slicing`, add two items. First, a ticket that prints a cell or a field before its producer lands is a slicing defect. The author reads each ticket's `What to build` as a committed slice. The evidence is a transitional ticket that printed a constant baseline cell it did not run.

Second, under the same heading, a ticket with more than six command-level tests names a second test file in its `Writes:` line. This rule applies when the sibling test file is near its line budget. The evidence is ticket 3, which stopped at its fence when eleven tests did not fit one file.

In `delegation-discipline.md`, under `## In the charge`, add one item. A charge names each fenced path that must still exist on return, so a fixture directory the fence names stays in the tree. Under `## Before the landing`, add one item. The coordinator runs `bench preflight build` on the integration source after every ticket commit and before the next charge. A delegate can remove a fenced path. The evidence is ticket 1, which deleted the fenced fixture directory, so the next charge failed on writes-resolve.

Write each item in ASD-STE100 per `.agents/skills/bench-craft-spec/references/ste-prose.md`. Match the surrounding items' wrap width and voice. State the rule, not the incident.
