# Which measures are reliable across harnesses?

Blocked by: none
Type: Research

### Question

For each supported harness, identify a stable source for tool-result bytes,
outer and child call counts, input and cached-input tokens, compactions, and
reasoning output. Record absent or ambiguous measures rather than estimating
them. Determine which raw facts Bench can own and which remain harness-owned
under FT231.

### Answer

The source assessment is complete with explicit unknowns.
The capability matrix and validation plan live in the [harness measures asset](../assets/harness-measures.md).
Documented contracts, pinned transcript observations, and installed behavior remain separate evidence classes.

The assessed Codex transcript supports its local text census and exposes usage and compaction records.
Cross-harness sources provide different measurement and result-control boundaries.
The current evidence does not establish portable nested-call attribution or complete-output interception across all harnesses.
No runtime compatibility claim follows from this assessment.

Bench retains its existing raw-call census and measurement ownership.
The harness reader supplies harness measures under FT231 and the existing capability registry.
Missing or ambiguous measures remain unknown rather than estimates.
