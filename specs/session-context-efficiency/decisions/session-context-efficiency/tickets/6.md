# Which findings deny, advise, or only measure?

Blocked by: #3, #5
Type: Grill

### Question

Classify each measurable pattern as deny, bounded rewrite, advice, or final
measurement. Define the false-positive and fail-open posture for every deny or
rewrite.

### Answer

The reviewer selects measurement and advice without new context-efficiency denials.
Commands apply bounded defaults through their current owners.
Guidance advises on wasteful call shapes.
The measurement record contains only observed results and explicit capability gaps.

Automatic wrapper replacement requires a runtime check before enablement.
That check proves complete-output preservation, correct execution status, and a working detail route.
Unsupported shapes or a failed spill retain the original result and report the limitation.
The wrapper never reruns a mutation.

A suspected inefficient call does not justify refusal or an unsafe rewrite.
Existing safety and authority guards retain their current behavior.
