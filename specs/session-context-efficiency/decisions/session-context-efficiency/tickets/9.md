# How does the work set numeric result budgets?

Blocked by: #3, #5
Type: Grill

### Question

Decide how new result projections receive numeric budgets after measurement.
The existing command owners retain their policies.
The single-session diagnostic cut does not establish a default budget.
Choose the evidence and reviewer checkpoint required before a new budget becomes behavior.

### Answer

The reviewer requires measurement before approval of new per-surface byte budgets.
Representative large-result cases supply the evidence.
Each budget proposal includes task-success results and the number of recovery calls.
The reviewer approves the proposed numbers before they become default behavior.

Existing command policies remain authoritative during measurement.
The census's 10,000-character diagnostic cut does not become a default cap.
The spec writer cannot select new numeric budgets as bounded discretion.
