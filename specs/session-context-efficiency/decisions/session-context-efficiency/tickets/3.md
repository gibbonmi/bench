# Which result surfaces require bounded defaults?

Blocked by: none
Type: Grill

### Question

Choose the first bounded projections across three boundaries. These are
agent-issued raw file, Git, test, and shell reads; Bench query defaults; and the
harness tool wrapper. Decide each selected boundary's default projection,
total-size signal, detail route, and operating guidance.

### Answer

The reviewer approves bounded defaults for raw file, Git, test, and shell reads, and for Bench queries.
The caller requests relevant sections, changed paths, failures, or selected rows.
The result discloses omissions and gives an explicit route to complete detail.
An explicit full read remains available when the task requires it.
Numeric budgets remain open until measurement supplies evidence.

The scope includes harness-wrapper overflow where the harness supports it.
The wrapper preserves complete output in an artifact before it returns a bounded result.
That result carries the execution status, bounded diagnostics, true size, and a detail route.
Ticket 5 establishes the capability evidence before any harness receives this promise.

Current command owners retain their policy authority under FT173.
This choice does not authorize a universal cap or removal of required evidence.
