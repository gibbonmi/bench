# Which cost leads prioritization?

Blocked by: none
Type: Grill

### Question

When call consolidation conflicts with a smaller result, which objective wins?

### Answer

Tool-result text is the primary objective. Call consolidation is secondary
(reviewer, 2026-09-11). A candidate that replaces several calls with one
concatenated raw response has not improved the primary cost. The map therefore
requires projection before aggregation and compares both measures separately.
