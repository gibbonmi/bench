# Which multi-target query outcomes belong in scope?

Blocked by: #4
Type: Grill

### Question

Choose whether selected multi-target queries cover worktree identity, path, and state, spec histories, or both observed families.
Each result preserves per-target failures and gives a route to complete detail.
The assessment records both repeated lookup sequences.

### Answer

The reviewer includes both observed query families.
Worktree queries return selected identity, path, and state fields for the requested targets.
Spec queries return a bounded history for each named spec.
Both query families preserve per-target failures and provide a route to complete detail.
This scope does not add a general batch-command facility.
