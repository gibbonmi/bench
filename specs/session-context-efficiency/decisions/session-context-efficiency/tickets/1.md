# What did the 2026-09-11 session actually spend on tool results?

Blocked by: none
Type: Research

### Question

Measure the root Codex session through the last completed phase, before the
reviewer's context-efficiency request. Separate tool-result-text concentration
from call count, classify the repeated shapes, trace existing owners, and name
what the available record cannot prove.

### Answer

The 323 outer tool calls returned 1,050,384 characters across 11,965 lines.
The median result was 320 characters, while 31 results at or above 10,000
characters contributed 73.2% of all tool-result text. Nine already-truncated
results still contributed 332,835 characters. Whole-file/history reads,
roadmap snapshots, Git snapshots, and the worktree population view dominate the
volume. Polling and eight one-at-a-time archive operations dominate visible call
repetition but contribute little text.

plan are in
