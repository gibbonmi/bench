# Which confidence scale and scoring rule apply?

Blocked by: none
Type: Grill

### Question

Does a claim state its confidence as an integer from 0 to 10, or as a real
number in [0, 1]? Does the Brier rule or the log rule score the pair?

### Answer

A stated confidence is an integer from 0 to 10 inclusive. The score
normalizes it to `p = n / 10`. The Brier rule scores each labeled pair as
`(p - label)^2`, with label 1 when the claim held and 0 when it was refuted.
A lower score is better. The log rule is excluded because it is unbounded.
