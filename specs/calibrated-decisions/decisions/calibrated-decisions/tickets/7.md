# Where do the pair and the score land?

Blocked by: #2
Type: Grill

### Question

Which artifact records each confidence-and-label pair, and which artifact
records the aggregate score per model, effort, and role?

### Answer

Each retro gains one calibration table. Each row holds the surface, the
claim, the status, the confidence, the label, and the model, effort, and
role. The scorecard README gains one calibration measure: the Brier mean,
the pair count, and the abstention count. Each provider routing row carries
that measure, under the existing ten-assignment aggregation cap.
