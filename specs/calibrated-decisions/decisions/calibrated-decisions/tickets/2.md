# Which decision surfaces carry a stated confidence?

Blocked by: none
Type: Grill

### Question

Bench labels four claim types later. The gate labels an acceptance row. The
coordinator labels a delegate done-claim row. The tree labels a review
finding. The retro labels the expected repair rounds. Which of these carry a
stated confidence in the first spec?

### Answer

Three surfaces carry a stated confidence in the first spec. A delegate
done-claim carries one confidence per acceptance row it claims. A review
finding carries one confidence that the finding holds against the tree. A
line declaration carries one confidence on its expected repair-round count.
An acceptance row itself carries none, because the delegate's row claim
covers it. A ticket `Writes:` path set carries none.
