## What to build

The implicit entries are `capture`, the spec folder, and the exact review pickup that `reviewrecord.RecordPath` derives. `paths-authorized`, `bench preflight review`, and the landing's source authorization read that one set. A leftover `## Ownership fences` section authorizes nothing.

The gather drops the `ownership fences empty` refusal, because an empty union authorizes only the implicit entries. The `fence-writes` row goes, and the row-list pins name the new order. The charge evidence `fence` block lists each path that `tickets.WritesPath` projects from every ticket entry, once, in ticket and entry order. The block keeps its name, and its schema description and the format reference name the ticket union.

The staleness audit scope keeps the spec and its tickets folder, and it reads each ticket's `Writes:` entries at the base and at the tip from committed objects in place of the fence section. The `source-not-fenced` route tells the operator to add the path to a ticket with `bench spec widen`, and it holds no `## Ownership fences` text.

The review-record fixture helper gains a ticket-writes form in place of its fence-entry form. New tests go into the two new test files, because the landing surface, review charge, and bootstrap test files sit near their structure budget. The review, decision, explicit-base, and landing journey test files are over their budget, so each edit there adds no net line.

The implement-spec staleness route drops its `fence-writes` clause, and a forbid anchor reds a restored clause. The map-only route drops its `fence-writes` red.
