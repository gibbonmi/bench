## What to build

The FT451 build measured where writer sessions spend their time. Orientation before the first edit took 37% of writer time, and each call costs about 10 seconds of model time. Writers made 81 `--help` lookups, read the whole spec 18 times, and ran whole packages where a focused run was enough.

The author and repair charge of `/bench-implement-spec` now names the spec sections that the ticket needs. It also tells the author to send independent reads in one turn, to run each development and witness test with `bench test --run`, and it prints the exact grammar of each Bench verb that the author runs.
