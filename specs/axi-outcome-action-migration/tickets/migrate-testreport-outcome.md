## What to build

`testreport.Command` constructs a shared outcome carrying its own kind and exit for each of its nine result classes before the existing renderer returns. The cancellation path keeps its bounded teardown — `SIGINT` to the child process group, a 2s wait, then `SIGKILL` — and the outcome is constructed after `cmd.Wait()` so no child outlives the call.

`migrate-structure-outcome.md` is OA3's accountable first claimant, under the tie-break rule that accountability goes to the ticket covering the spec map's first-enumerated OA3 family (structure, before models, testreport, guards, outline, roadmap, status, handoff, dashboard, and worktree query), so this ticket claims OA3 as defense in depth.

Refresh precondition (OA3 is not TDD-able until OA1 and the prerequisite carrier land): `internal/axi` must exist as Go package `axi` with `go doc ./internal/axi Outcome` resolving, and `migrate-output-adapter.md` must have landed. `cmd/bench/axi_compatibility_test.go` is an unchanged input this ticket only runs.

Write the owner test `TestTestreportOutcomeRouteByResultClass` in `internal/testreport/testreport_test.go`: one subtest per result class, each driving the real `testreport.Command` against a `t.TempDir()` module with a stub `go` on PATH, and asserting the constructed outcome's kind and exit. Every subtest sets its own `context` deadline via `bounds.TestDeadline(4*time.Second)` so a stub that never exits fails as a deadline rather than a hang.
