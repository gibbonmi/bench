# Migrate publication outcomes and actions

Blocked by: none
Ownership fence: `internal/publication`
Integration surfaces: shared outcome carrier→`internal/axi` exercised by PB1; shared action carrier→`internal/axi` exercised by PB1; compatibility oracle→`cmd/bench/axi_compatibility_test.go` exercised by PB1; final contraction→contract-outcome-action-routes.md
Contracts: the operation name, durable result kind, exact exit, and the `meta` row's `next_action` token cross `internal/publication`'s state machine (`RunFirstPublication`, `RunStagedPublication`, `RunPromotion`, `RunRollback`, `LoadRecord`)→`printRecord`, membership is `prepare`, `submit`, `promote`, `rollback`, `status`, order follows the durable `Record.Transitions` sequence, absence is the schema-version-zero `none`/`prepare` meta row, and the `release_index_sha256` that authorizes publication is derived only by `VerifyApprovedSet` over the on-disk release index, asserted by PB1 against the real `Record`
Closure: PB1/prepare, PB1/submit, PB1/promote, PB1/rollback, PB1/status, PB1/record-authority, PB1/next-action-input, PB1/release-index-preimage, PB1/no-record-empty, PB1/failed-exit

## What to build

Each of the five publication operations reached by `publication.Command` constructs a shared outcome carrying its own durable kind and exit, and each `next_action` value becomes a typed action before `printRecord` writes the `meta` row. The durable `Record` stays the sole authority: `nextActionForInProgress` keeps reading only `Record.Transitions` and `Record.Provenance`, and `VerifyApprovedSet` keeps deriving `release_index_sha256` from the `dist/preflight/release-index.json` bytes. State-machine authority does not move and no public byte or exit changes.

Refresh precondition (OA6 is not TDD-able until the prerequisite carriers land): `internal/axi` must exist as Go package `axi` with `go doc ./internal/axi Outcome` and `go doc ./internal/axi Action` both resolving. `cmd/bench/axi_compatibility_test.go` is an unchanged input this ticket only runs.

Write the owner test `TestPublicationOutcomeRoutePerOperation` in `internal/publication/command_test.go`: one subtest per closure token driving the real `publication.Command` against a `NewFixtureRegistry(t.TempDir())` and a `t.TempDir()` root, reloading the durable record in the process-boundary cases, and asserting the constructed outcome's kind, exit, and typed action.

## Acceptance

- [ ] [PB1] (covers OA6) each of the five publication operations constructs a shared outcome carrying its own durable kind and exit and a typed `next_action`, with the durable record still the sole authority and byte-identical stdout and exits.
