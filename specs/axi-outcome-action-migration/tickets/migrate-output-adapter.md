## What to build

`outputCommand` in `cmd/bench/main.go` carries a shared outcome instead of a bare `(string, int)` pair, and each of the six cmd-local returned-output members — `anchorsCommand`, `commandsCommand`, `roadmapCommand`, `treeHash`, `resolveModel`, `testCommand` — constructs that outcome with its own kind and exit before the adapter prints. Public bytes and exits are unchanged.

Refresh precondition (OA1 is not TDD-able until the prerequisite carrier exists): before starting, `internal/axi` must exist as Go package `axi` and `go doc ./internal/axi Outcome` must resolve the outcome carrier authored by `specs/axi-carriers-and-registry/tickets/introduce-outcome-carrier.md`. `cmd/bench/axi_compatibility_test.go` must exist from `axi-compatibility-oracle` and stays an unchanged input this ticket only runs. If either path or symbol is absent, stop and report rather than building a local carrier.

Write the new owner test `TestOutputCommandRoutesEveryCmdLocalMember` in `cmd/bench/main_test.go`: it drives each of the six members through `Command{...}.Run` with a recording observer and asserts the observed outcome kind and exit per member, so a byte-equal bypass is red even though the oracle stays green.

## Acceptance

- [ ] [AD1] (covers OA1) `outputCommand` and each of the six cmd-local returned-output members construct a shared outcome carrying that member's own kind and exit, with byte-identical stdout and exit codes.
