## What to build

`internal/conformance` derives every production member from the root registry and the nested
family dispatchers, compares each member's declared applicable shared routes against the routes
observed by driving that member's real production entry, and refuses any member whose observed
set differs from its declared set. In the same ticket, every superseded local carrier derivation
left behind by the nineteen migrations is deleted and every exported shared symbol with no
remaining consumer is removed or given a named public-API owner. `projects/benchkit.md` is on the
fence because it restates the conformance check this ticket registers.

The member universe is 81: the 48 root entries `commandRegistry` declares in `cmd/bench/main.go`,
plus 31 nested members — `worktree` exec/path/list/create/release/clean/recovery (the seven
`internal/usage/worktree.go` `worktreeCommands` entries) plus the default subshell surface;
`spec` implemented/retire/history; the `spec build` family home (the no-operation surface the census grades at its own row); the nine `spec build` operations `buildOperationOrder`
declares; the nested `gate pin` operation (`internal/gate/gate.go`'s `case "pin"`, distinct from the root `gate-pin` plumbing entry); `release` prepare/submit/promote/rollback/status; `gate-go` gofmt/test; `worktree-hook`
create plus its default remove; and `release-preflight`'s two `--mode` values, verify and publish
(`--phase` is a flag over a mode, not a member). Every surface
`ft173-axi-surface-census.md` names falls inside that union — the census enumerates seven
conforming query surfaces (`anchors`, `learnings`, `maps`, `guards`, `diff`, `coverage`, and
`worktree list`), each already a declared member — so the census is the reconciliation input that
catches a member the registries drop, not a source of additional members.

Refresh precondition (OA9 is not TDD-able until every migration lands): all nineteen blockers must
be landed, `internal/axi` must exist as Go package `axi` with `go doc ./internal/axi Outcome` and
`go doc ./internal/axi Action` resolving, and the root and nested registry declarations enriched by
`axi-carriers-and-registry` must carry the per-member applicable-shared-routes metadata this check
compares against. If that metadata is absent, stop and report rather than inventing a parallel
catalog. `cmd/bench/axi_compatibility_test.go` exists as an unchanged input this ticket only runs.
Re-derive the member list and the legacy-symbol list from the tree at that point rather than from
this ticket's account of them.

Write the owner tests `TestEveryDeclaredMemberReachesTheSharedRoute` and
`TestNoSupersededCarrierDerivationSurvives` in `internal/conformance/axi_route_census_test.go`.
