## What to build

With every migration landed, one registry-derived conformance check proves the whole
contraction: each of the eight aggregate owners the FT173 surface census names under
principle 4 — guards, outline, roadmap, worktree, spec-build, publication, status, and
dashboard — is observed reaching the shared aggregate route, each of the 81 production
registry members declaring an empty disposition is observed reaching its declared route,
and the superseded local carriers named below no longer exist in the tree. The 81 members
are the 48 `commandRegistry` roots plus the 33 nested members `declare-empty-dispositions.md`
enumerates. `internal/toon`'s emitted-row-count header is retained, not contracted: it is
the shared encoder's own fact.

Contraction removes only the local carrier mechanics the shared route replaced. Domain
derivations (totals, fingerprints, durable records, absence authority) and the existing
exact renderers stay. An exported symbol left with zero consumers after contraction is
residue and is removed with it.

The census asset is read as the owner inventory but is not written by this ticket; it is an
existing decision-record path. `projects/benchkit.md` restates the conforming AXI surface,
so it is on this ticket's fence.

Tree condition that must hold when this ticket is refreshed: `internal/axi/aggregate.go` and
`internal/axi/empty.go` exist with their exported `Aggregate`, `Fact`, and `EmptyClass`
symbols, and every blocker ticket above has landed. Re-derive the residue list below from the
tree before building — the exact call sites are named here as of authoring, not as a
substitute for the search.
