# AXI query disclosure

Status: staged

Decision source: reviewer-confirmed current conversation on 2026-08-12 — repair only the false reusable-invocation prerequisite, authorize that missing owner to land atomically with its first public query consumer, retain the harness-phase addition, preserve QD1–QD6 and the signed QD5 ledger, and keep Fable as the final cross-harness implementation reviewer.

## Problem

After the coherent-diff migration, the remaining approved query surfaces — `anchors`, `learnings`, `maps`, `guards`, `coverage`, and `worktree list` — still end at their facts: a stale guard names no repair, an invalid map names no template, an unchecked coverage map names no check command. Help spellings are inconsistent (`worktree list` hand-parses `-h/--help` and rejects bare `help`), no gate check derives AXI conformance for the approved set as a set, and `craft-cli` still documents seven of the ten principles, so guidance cannot ask for what it never names.

## Solution

Complete contextual disclosure across the remaining approved surfaces as additive transitions on their default extraction/discovery responses: each keeps its primary bytes, streams, exits, and argv exactly and appends one `help[]` block through the renderer landed by `axi-coherent-diff`, with the honest empty block for terminal results. Help/usage responses and non-discovery modes remain their existing contracts: hook-injected `guards --brief`, `maps --count`, the `maps --template` document, and `coverage --check` neither gain nor require `help[]`. This spec adds the missing reusable executable-invocation kind and the harness-phase kind, landing both atomically with `maps` as their first public query consumer. Route `worktree list` through `usage.Parse` so the three sole-token shared help spellings apply without changing any other argv response, close one registry-derived conformance check over the whole approved set, and rewrite `craft-cli` to state all ten principles and the exact approved surface. The spec's action inventory starts from `decisions/byte-preserving-axi-foundation/assets/ft173-command-help-inventory.md` and the signed harness-log leverage review taken across the FT173 builds, with every observed opportunity given one disposition.

Line: gpt-5.6-terra / high. The per-surface action cases are enumerable but omission-sensitive, and inventing busywork on terminal results is the equal and opposite failure.

Every non-sole invocation remains byte-identical to the pre-change parser. Line: gpt-5.6-terra / medium. The migration is mechanical but changes the accepted-argv language, so the fixture must name exactly the new spellings and enumerate the rejected partitions.
3. As a kit maintainer, I want one registry-derived conformance check that grades the complete approved AXI set — the six root queries and `worktree list` — for structured stdout, definitive empties, honest exits, help spellings, and the help envelope, so surface membership and conformance cannot drift apart. Line: gpt-5.6-terra / high. The check must derive membership independently so flipping a surface in or out of the set is red in both directions.
4. As an agent author, I want `craft-cli` to state all ten principles, the help-block contract, and the exact approved surface, so future generation neither omits contextual disclosure nor widens AXI to operational commands. Line: gpt-5.6-sol / high. Generation-guiding kit prose takes the leverage override.
5. As the reviewer, I want the harness-log leverage review recorded as an evidence asset in which every observed opportunity — a missing or wrong `help[]`, a repeated tool-call sequence one query could replace, an output shaping agents perform themselves — receives exactly one disposition: folded into this spec, already owned, declined with a reason, or routed to a named roadmap item. Line: gpt-5.6-terra / high. An undispositioned observation is scope that leaks or value that silently drops.

## Implementation decisions

- Every addition is an additive transition per the compatibility contract: primary bytes, streams, exits, and accepted argv are unchanged except where a named old-to-new fixture states the delta (the three sole-token `worktree list` help spellings; the appended help block on each default extraction/discovery response that reaches a truthful disclosure seam). Usage, early refusal, and non-discovery modes stay byte-identical. The one refusal-shaped disclosure case is `learnings` malformed-among-parsed: it has already produced typed rows and a named repair, so it preserves those rows, its diagnostic, and exit 1 while appending that repair action.
- Help derivation composes `RenderHelp` from `axi-coherent-diff`; each surface's command function derives its actions from the same typed facts it already renders, and no shared renderer infers domain semantics. The current `internal/axi` owner exposes only the diff-specific `InspectFull` and `RetryDiff` actions, so this spec adds a reusable executable-invocation kind that carries every known argv token plus only explicitly unknown future-input slots, and a harness-phase kind for `/bench-what-next` and `/bench-shape-idea` that renders canonically as a phase rather than a shell command. Both kinds and the renderer's kind-specific phase dispatch land atomically with `maps`: an invalid map consumes the invocation kind and a frontier consumes the phase kind. The existing diff actions and every byte they emit remain unchanged; the renderer changes only to omit the `bench ` prefix for the typed harness-phase row.
- Action derivation is per matching row, not per surface: every actionable row yields its own action with its row's values carried (each orphaned worktree row its own `bench worktree clean <path>`), exact duplicate templates dedupe, and producer order is preserved. For `worktree list`, that means assignments in the intent ledger's serialized ID order followed by Git registrations in their producer order; tests consume that order and never re-sort it independently.
- `anchors` remains terminal: success and empty results append the honest empty block. Empty-result help is the empty block everywhere — absence is the answer, not a prompt to invent work.
- `worktree list` moves onto `usage.Parse` with a declared grammar whose command-local option recognizes help only when the spelling is the sole argument, satisfying the existing `subcommand-routing` posture without a parser bypass. The accepted delta is exactly sole-token `--help`, `-h`, and bare `help`; `--help extra`, `-h extra`, `help extra`, bare `--`, `-- x`, the empty token, one ordinary extra, and multiple ordinary extras preserve their pre-change stdout, stderr, and exit exactly. The option changes no other grammar.
- Known action arguments accept exactly tab (U+0009), newline (U+000A), and carriage return (U+000D) from the control-rune class. POSIX single-quote rendering preserves the source bytes, the official `toon-go` decoder recovers the help cell, and a POSIX shell argv probe byte-compares the executed argument to the source. Every other `unicode.IsControl` rune — the remaining C0 set, DEL U+007F, and C1 U+0080–U+009F — remains refused. A disclosure value the renderer cannot represent never replaces a computed primary response or changes its exit: the surface appends the honest empty help block instead. This fallback covers known argv and `why` cells, including coverage/worktree paths and an invalid-map diagnostic path.
- Production AXI membership is declared in the production registry itself: the registry entry gains an AXI-scope declaration and the worktree entry declares its one AXI subcommand (`list`), so nested membership is derivable rather than guessed. The conformance check reads those declarations by the same AST route the existing `subcommand-routing` check uses, extended to the nested declaration; the approved-set expectation (the six root queries and `worktree list`) is an independently authored conformance expectation — the AGENTS.md independence exception, necessary so flipping a member in either direction is red — and every other member is an explicit exemption. Per-member grading is an exact predicate list, not a family: structured TOON stdout on success, the definitive zero-row empty, refusal via structured error on stdout with exit 1, an unknown flag failing usage with exit 2, deep-cwd invocation routing identically, the shared help spellings (`--help`, `-h`, bare `help`) answering with usage on exit 0, and the appended `help[N]{cmd,why}` block or honest zero-row block. Envelope grading for `cmd/bench`-owned surfaces lives in a package-main conformance test beside the registry. `projects/benchkit.md`'s AXI seam advertisement is updated in the same ticket.
- A second conformance check cross-checks guidance against production: `craft-cli`'s advertised approved-surface list must equal the registry-declared AXI set and its principle count must be exactly ten — guidance omitting a member, adding one, or claiming more or fewer principles is red.
- `craft-cli` states the ten principles with the per-surface application, the `help[N]{cmd,why}` contract including the honest zero-row empty form, and the approved surface; it does not advertise `--fields` or any behavior this sequence does not ship.
- The signed leverage review was the build's first ticket and remains the hard checkpoint before any QD1–QD4 implementation ticket. Its approved ledger names the Claude and Codex corpora, representative recent Bench work, unavailable sources, and one disposition for every observed opportunity. The checkpoint is satisfied; any later fold that would change locked coverage still requires a reviewer-approved spec amendment before implementation proceeds — never a silent build-time widening.

## Testing decisions

- TDD attaches per surface at the existing command seams with real fixtures (a stale guard manifest, an invalid map, a mapped coverage row, an orphaned worktree row); each surface's action cases, honest-empty cases, and named disclosure-relevant refusal cases get independent assertions.
- The additive contract is proved per surface by old-to-new paired fixtures (QD6). For each named extraction state that reaches disclosure, the pre-change response is checked in and the candidate may differ only by the appended `help[]` block; `worktree list` additionally permits exactly the QD2 sole-help argv delta. Named early refusals instead require byte-identical old/new stdout, stderr, and exit. The exhaustive state inventory is: anchors populated and empty; learnings open, drained, absent, malformed-among-parsed (rows plus diagnostic plus help, exit 1), unsupported-schema early refusal, empty-file early refusal, malformed-UTF-8 early refusal, unreadable-file early refusal, and wrong-file-type early refusal; maps frontier, invalid-map diagnostic, empty, and complete; guards stale, unwired, clean, partial-timeout incomplete scan, and enumeration-timeout incomplete scan; coverage mapped rows, repairable mapped rows, mapped zero-row, historical, and no-map; worktree active, orphaned, empty, and non-actionable terminal rows. States that share bytes may share a fixture only through an explicit table alias naming each state.
- The `worktree list` grammar migration is proved by an accepted/rejected-argv paired delta over sole-token `--help`, `-h`, and `help`; multi-token help; bare and value-bearing `--`; empty; one extra; and multiple extras. Every row carries old/new stdout, stderr, and exit, with only the three named sole-token spellings differing.
- The control-value test decodes the rendered help table with the official `toon-go` decoder, executes the decoded command through a POSIX shell argv probe, and byte-compares its recovered argument. Separate counterexamples enumerate the supported three-rune set and the refused remaining C0, DEL, and C1 sets; public surface tests prove both supported rendering and unsupported-value primary-response preservation.
- Conformance tests mutate membership in both directions — drop an approved surface, add an operational command — and require red; envelope grading reuses the real command outputs.
- Mutation discipline for actions follows the live owner counterexamples in `internal/axi/action_test.go`; the new reusable invocation adds owner counterexamples for dropped known argv, guessed values, undeclared placeholders, and prose-as-command, the harness-phase kind adds canonical-phase and never-shell-command counterexamples, and each surface adds only its derivation cases.

### Edge inventory

- Error path — early refusals remain byte-identical and gain no disclosure. `learnings` malformed-among-parsed is distinct: typed rows and a named repair already exist, so rows, diagnostic, and exit 1 are preserved while help is appended. An unsupported disclosure-only value never replaces either kind of primary response or changes its exit; it falls back to honest empty help.
- `anchors` usage refusal — already owned: the inventory names the usage/2 grammar line itself as the sufficient help, so no `help[]` duplication is added.
- Empty or absent input — the honest empty help block on every empty result; absent journal, no maps, and clean guards keep their existing definitive empties.
- Boundary values — surfaces with one row versus many derive identical action shapes; help blocks are derivation-bounded.
- Malformed input — an invalid-map default extraction keeps its diagnostic and gains only the named template-plus-path action when both `cmd` and `why` are representable; otherwise it preserves that diagnostic and exit with honest empty help. Learnings' six refusal classes follow the exact QD6 split. Coverage `--check` and its refusals are non-discovery contracts and never gain disclosure.
- Interrupted or partial state — `guards`' incomplete scan keeps its honest aggregate; its help names `bench link` only for the stale/unwired class, never for timeout incompleteness.
- Re-run idempotency — appended help derives from the same facts as the response, so repeated calls return identical bytes.
- Process-boundary lifecycle — fixtures run the public commands; conformance grades rendered output, not internal state.
- Hostile environment — known action arguments accept exactly U+0009, U+000A, and U+000D from the control-rune class and round-trip through official TOON decoding plus a POSIX shell argv probe. The remaining C0 controls, DEL U+007F, and C1 U+0080–U+009F are refused as disclosure values and trigger honest-empty fallback; the same fallback applies to an unsupported `why` cell. Deep-cwd behavior per surface is unchanged and graded by QD3.
- Command self-observation — help derivation cannot mutate the facts it reads.
- Special files and dangling symlinks — no new discovered-path reader; existing surface refusals are unchanged.

**Won't handle:** contextual disclosure for operational families outside the approved set (status, handoff, worktree mutations, release, adoption, plumbing) — each needs its own evidence and reviewer decision; a routed roadmap item from QD5 is the only path in.

## Out of scope

- Re-introducing any spec-build surface or lifecycle envelope — the family is retired with the provisional lifecycle, not deferred, so no spec-build prerequisite exists.
- The landed diff-specific `InspectFull` and `RetryDiff` actions and coherent diff snapshot are consumed inputs and remain out of scope. The reusable executable-invocation kind, harness-phase kind, and the renderer's kind-specific phase dispatch are in scope here; no additional coherent-diff edit or gate run is required.
- `--fields`, default-schema width changes, family-home changes on any surface in this spec, or rewriting the diff contract `axi-coherent-diff` lands.
- Widening AXI to any operational family.
