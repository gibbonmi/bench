## What to build

The shape-idea command teaches the landed shape. The map is an index. A decision ticket is one file under the map's tickets folder, and the answer lives only there. Decisions so far holds one gist per resolved ticket, and Notes holds the map's standing preferences. The shaping worktree lease is the claim. The command points at both templates and the assets folder.

The command names a ticket by its title with its number beside it in prose to the reviewer. It carries FT99's rule: a grill recommendation that asserts current-code behavior names the evidence read in the current session. The write-spec command moves the topic folder into the spec as one unit.

`CONTEXT.md` defines decision map, map index, decision ticket, and gist, each with an Avoid list. ADR 0020 records the three decisions and names no path. The README and the field guide describe the split shape. The README keeps `Decision maps are situational`.

Each sentence listed under the spec's Further notes gets a registry anchor, a mutation-table row, and the fixture copies of the two command files updated. The needles that pin the old `decisions/assets/`, move, and retirement wording change with their prose.
