# Workflow parity

Blocked by: none
Type: Grill

### Question

Which behavior must remain consistent across the qualified harness interfaces?

### Answer

Cover the complete Bench workflow and the local tools that workflow requires.

- Command execution and file access.
- Skills, hooks, and required permissions.
- Worktrees, reviews, and recovery.

Assess desktop-specific capabilities explicitly.
The outcome does not require parity for every available tool.
