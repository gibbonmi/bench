# Configuration consistency

Blocked by: none
Type: Grill

### Question

Which settings must agree, and which settings may remain separate?

### Answer

The repository's Bench rules, skills, hooks, command resolution, and required permissions remain consistent.
Personal preferences, credentials, models, and chat history may remain separate.
Report a configuration conflict instead of silently overwriting the conflicting setting.
This outcome does not require synchronization of personal Codex settings.
