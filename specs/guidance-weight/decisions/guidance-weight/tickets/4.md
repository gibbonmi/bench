# Which light-path fixes go to a write delegate?

Blocked by: none
Type: Grill

### Question

`.bench/BENCH.md` says "Dispatch that fix to a fresh write delegate" under "Delegate each light-path fix", but the light-path table says "no write-delegate". Which fixes does the dispatch cover?

### Answer

Every light-path fix that comes from a `bench learning` entry or from a drain goes to a fresh write delegate. The delegate runs on the mid tier at high effort, in its own bench worktree. Only a light-path change that the reviewer asks for directly in the session goes inline under the table. Inside a build, the hold rule of `/bench-implement-spec` applies.

Commit 79512031 set the rule for a learning, and commit e17be081 extended it to every drain fix.
