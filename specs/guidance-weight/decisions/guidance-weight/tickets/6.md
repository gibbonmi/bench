# What byte limit does each existing budget row start with?

Blocked by: #3
Type: Grill

### Question

When the budget table changes from lines to bytes, each existing row needs a byte limit. What limit does each row start with?

### Answer

Each exact row starts at its file's size in bytes when the measure changes, rounded up to the next multiple of 100 bytes. A glob row starts at the size of the largest file that only the glob row classifies, rounded up the same way. No subject can then grow without an edit of the table.

`.bench/BENCH.md` keeps its rounded starting limit until #11 sets its lower bound.
