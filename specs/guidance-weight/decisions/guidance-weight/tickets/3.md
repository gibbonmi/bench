# Which measure does the prose budget use?

Blocked by: none
Type: Grill

### Question

The `guidance-prose-budgets` check counts physical lines (`internal/conformance/prose_budget_test.go:206`). A paragraph of 113 words on one line counts as one line, so the line budget does not limit size. Which measure does every row of the budget table use?

### Answer

Bytes. Every row of the `### Guidance prose budgets` table in `projects/benchkit.md` limits its subject in bytes, and the check counts the bytes of the file. Bytes ignore line wrap and track tokens most closely, and the gate has no tokenizer.
