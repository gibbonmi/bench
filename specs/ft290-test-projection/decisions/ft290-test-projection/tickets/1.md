# Which occurrence items join the destination?

Blocked by: none
Type: Grill

### Question

Three items are in the FT290 occurrences but not in the row body. The first is
`--run` with `--check system`. The second is the compile error on a
non-compiling `--package`. The third is one failures row for each diagnostic.
Which of them does the destination hold?

### Answer

The destination holds `--run` with `--check system` and the failures row unit.
The compile error on a non-compiling `--package` is a reviewed exclusion,
because commit `4ff47076` shipped it on 2026-09-12 with
`TestRunPatternReportsCompilerDiagnostic`.
