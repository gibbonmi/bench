# What proves that the selected check ran?

Blocked by: none
Type: Grill

### Question

A green named-check result does not show that the selected check ran. A green
package is also not distinguishable from a run with no tests. Which predicate
is the proof?

### Answer

Each named-check result carries one row, `check[1]{name,kind,tests_run,subjects}`.
A Go-backed check prints its `tests_run` count and `subjects` 0. The prose
check prints `tests_run` 0 and its `subjects` count. The zero rule reads
`subjects` for the prose check and `tests_run` for each other check, and a
zero count exits 1. Each packages row also carries a `tests_run` cell.

The reviewer fixed the row schema on 2026-09-19.
