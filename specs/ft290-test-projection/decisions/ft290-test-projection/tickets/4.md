# What does the fixtures face print?

Blocked by: none
Type: Grill

### Question

What does `bench test --check <name> --fixtures` print, and does it run the
check?

### Answer

The face prints one row for each fixture that the check owns: the family, the
fixture, and the repo-relative path. The owner is the one inventory owner that
`canary.Fixtures` resolves, so a `CHECK` marker comes before the family
binding. The face runs no test. A check that owns no fixture prints an empty
table at exit 0.

The reviewer approved the inventory owner on 2026-09-19.
