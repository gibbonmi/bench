# What does the check inventory print?

Blocked by: none
Type: Grill

### Question

`bench test --help` already prints the check names. What does
`bench test --checks` add?

### Answer

`bench test --checks` prints one row for each named check at exit 0. A row
holds the name, the kind, and the count of owned fixture families. The kind is
`conformance`, `system`, or `prose`. The count is the number of families in which the check owns one fixture or
more, by the inventory owner of ticket #4. The help text and this table read
one source.

The reviewer approved the count source on 2026-09-19.
