# What does the prose check print on green?

Blocked by: none
Type: Grill

### Question

`bench test --check prose` exits 0 with no output on green. What does a green
result print?

### Answer

A green result prints the `check` row of ticket #3 with `tests_run` 0 and the
count of graded subjects in `subjects`. The result has no packages table,
because the prose check grades no Go package. `--full` lists each graded
subject. A prose run that grades zero subjects exits 1.

The reviewer fixed the zero-subject edge on 2026-09-19.
