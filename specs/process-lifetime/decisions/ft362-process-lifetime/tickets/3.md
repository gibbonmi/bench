# Which behavior does the migration preserve?

Blocked by: none
Type: Grill

### Question

Which caller contracts remain fixed during the migration?

### Answer

The reviewer selected all current production process-group callers.
Preserve each caller's normal-exit behavior and fix shutdown defects explicitly.

Preserve the following distinctions:

- Gate interruption and timeout retain separate causes and exit policies.
- Gate and builder completion still require their existing group cleanup.
- Ordinary command callers gain no automatic normal-exit group kill.
- Testreport retains complete output decoding and package-result validation.
- Worktree commands retain environment, stream, and assignment behavior.
- Shift retains interruption, deadline, and evidence distinctions.
- Release callers retain evidence promotion and publication authority.
- The Linux builder retains its parent-death signal.

The shell exit-status defect remains a separate repair.
The shared outcome must retain the child result so that the repair can consume it.
The migration must not silently fold that repair into a preserving ticket.

Keep current grace periods where they exist.
Recommend a two-second grace for new catchable shutdown paths.
Recommend a separate three-second final cleanup deadline after forced termination.
Use the bounds owner for these policies.
Ticket 6 must verify this recommendation against the actual stream shapes.

These deadlines bound shutdown attempts, not ordinary command duration.
A probe that needs different values must record its evidence before the map becomes ready.
