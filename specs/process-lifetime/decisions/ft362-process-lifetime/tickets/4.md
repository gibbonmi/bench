# What happens when cleanup cannot finish?

Blocked by: none
Type: Grill

### Question

What may Bench claim when forced termination or output drain remains unresolved?

### Answer

The reviewer selected bounded failure with retained evidence.
After the final deadline, return a failure that names each unresolved cleanup obligation.

Retain the affected worktree, build output, or evidence directory.
Preserve the observed child outcome alongside the cleanup failure.
Do not publish, certify a green result, or report successful cleanup.

Treat permission errors and an uncertain group state as unresolved.
Do not interpret every failed group probe as proof that the group disappeared.
Do not close caller-owned streams merely to manufacture completion.

Any remaining waiter must retain only the resources it still needs.
The caller must not remove artifacts that an unresolved child can still change.
Ticket 6 must prove the ownership and recovery route for this case.

This contract does not promise to stop an unkillable OS task.
It requires a bounded caller result and an honest record of incomplete cleanup.
