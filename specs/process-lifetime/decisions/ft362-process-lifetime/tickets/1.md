Blocked by: none
Type: Research

### Question

Which current production sites start process groups, and what policy does each retain?

### Answer

Source inspection at commit `37ac80b8adeff4ecbd57f3d813ff8937f2bcbc68` gives the following census.
No process test or benchmark ran for this map.
A raw file count also includes comments and platform files.

| Site | Current normal completion | Current shutdown mechanism |
|---|---|---|
| `internal/gate/runner.go:47` | Kill and drain the remaining group | INT for interruption; TERM for timeout; grace then KILL |

The shift signal and deadline paths call killAdapter.
See `internal/shift/loop.go:221` and `internal/shift/loop.go:241`.
The map includes cancellation during startup, because the adapter publishes its command before Start.

The gate and builder drain loops wait for ESRCH without a deadline.
See `internal/gate/runner.go:88` and `internal/runbinary/runbinary.go:295`.
The scanner can wait on a resistant direct child.
The external phase runner's direct child already has CommandContext cancellation.
Its distinct risk includes descendants that retain stream descriptors.

The Linux builder sets Pdeathsig; the Darwin builder does not.
See `internal/runbinary/sysprocattr_linux.go:10` and `internal/runbinary/sysprocattr_darwin.go:9`.
