# Which tests must survive?

Blocked by: none
Type: Grill

### Question

How does consolidation preserve test purpose?

### Answer

Keep central tests for lifetime mechanics and integration tests for caller policy.
The roadmap's proposed single group-kill test cannot prove that every caller uses the owner.

The spec must attach tests to these observable failures:

- A resistant child survives the initial signal.
- A descendant retains an output descriptor after the leader exits.
- Cancellation arrives during startup.
- A group probe fails without proving absence.
- Output decoding remains incomplete when cleanup expires.
- A caller reports success or removes evidence after incomplete cleanup.
- A normal nonzero exit loses its status or output.
- A caller retains an old private lifetime loop.

Use actual local child processes for signal and descriptor behavior.
Use controlled faults only for states that real processes cannot create reliably.
Keep each test's production entry point and its cleanup authority explicit.

`internal/worktree/exec_test.go:349`, and
`internal/worktree/subshell_test.go:76`.

Record a demonstrated red before removing a duplicated expectation or expensive journey.
