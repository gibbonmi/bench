# Omit an exact multiline probe substring from a file

Blocked by: none
Writes: internal/probe/command.go, internal/probe/probe.go, internal/probe/mutation_input.go (new), internal/probe/refusal_test.go, internal/probe/omit_file_test.go (new)
Covers: none

## What to build

Add `--omit-file <path>` as a mutation form whose file bytes are the exact substring removed from the probe subject.
Report the mutation as `omit` so the verdict schema keeps one meaning for omission regardless of where the substring came from.

## Acceptance

- [ ] `bench probe <subject> --omit-file <path> ...` removes one exact multiline byte sequence, runs the selected probe, restores the subject, and reports mutation `omit`.
- [ ] The grammar accepts exactly one of `--swap`, `--omit`, `--unwrap`, and `--omit-file`; `--with` remains valid only with `--swap`.
- [ ] An absent, empty, unreadable, symlink, directory, special, or oversized mutation file refuses before a subject write or test run.
- [ ] A zero-match file-backed omission reports cause `substring-miss`, and a multiple-match omission keeps the ambiguous-mutation refusal.
- [ ] The mutation-file read is bounded and does not follow a symlink.
