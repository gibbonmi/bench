# Does the gate enforce the single read at the verb entry?

Blocked by: none
Type: Grill

### Question

Each verb reads the kit root, the Bench home, and the clock once, at its verb
entry. Does the gate enforce that rule?

### Answer

Yes. The static census in the worktree package adds a refusal. A source
function below a verb entry that reads the Bench home, the clock, or the kit
root is reported with its file and line. In the same change, the serial
ceiling drops from 46 to the new serial count.
