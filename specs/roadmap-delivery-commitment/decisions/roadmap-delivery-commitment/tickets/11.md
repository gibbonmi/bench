# How do existing projects adopt the commitment?

Blocked by: #2, #3
Type: Grill

### Question

Does the reviewer approve an initial commitment from existing work, or does Bench adopt the previous sequence automatically?

### Answer

An existing project adopts the rule through an explicit initial commitment approved by the reviewer. The worker inventories current work and proposes that commitment. Already-authorized runs may finish. Bench does not infer approval from the previous priority order.
