Blocked by: none
Type: Grill

### Question

Which release machinery should remain?

### Answer

Keep first publication, resume, promotion, and rollback through the current adapters.
Keep fixture staging as a tested path.
Keep public npm staging explicitly unsupported before lock or registry effects.

The staged path has an actual fixture caller at `internal/publication/command.go:225`.
The npm refusal occurs at line 206.
Its entry-point test is `internal/publication/command_adapter_test.go:316`.
The roadmap's claim that this path has no test is false.

Do not delete the state machine to remove unsupported npm methods.
The state machine owns real sequencing and recovery behavior.
A future public staging implementation needs its own capability and qualification decision.
