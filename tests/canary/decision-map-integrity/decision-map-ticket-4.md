# Agent-line enforcement scope — own-family-only or any bound tier?

Blocked by: none
Type: Grill

### Question

A delegation names a model of the asking harness. Does the hook accept only
that harness's values, or any bound cell of the matrix?

### Answer

Any bound tier value. Enforcement stays permissive, and a model on no cell
still denies. Steering to the native family is advisory, not enforced.
