## Q4: reviewer decisions and validation

### Proposed grill frontier

1. Should FT311 derive complete delegate packets, including native review-axis preparation?
   Recommend yes: extend existing preflight evidence instead of another handwritten charge layer.
2. Which post-landing effects should one command own, and how should an interrupted effect resume?
   Recommend explicit effect records and independent retry, with publication state always visible.
3. Which work may move to a lower-tier delegate?
   Recommend cheap trials for exact collection and covered leaf repairs; mid for repair triage and semantic review.
4. Does cheap prose repair include normative kit guidance?
   Recommend no policy change: retain mid/high authorship while automating diagnostics and fact collection.
5. Should the candidates form one spec or several independently reviewable slices?
   Recommend grouping by command owner and authority boundary; the reviewer chooses the scope.

These are proposed questions, not recorded reviewer answers.
The old fold-lane question needs reconciliation with the tree before any grill uses it.
