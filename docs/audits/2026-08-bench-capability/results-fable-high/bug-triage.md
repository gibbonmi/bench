# Bug triage — every reported defect, reproduced or not, with economics

loop named; (3) invariant/workflow affected; (4) does the component survive the target
architecture (it does for all — the target is incremental); (5) fix / replace / delete /
defer / document; (6) regression discriminator; (7) disposition. An unreproduced bug is
UNCONFIRMED. Ledger ids refer to `reconciliation-ledger.md`.

## Bug-fix economics summary

- Every reproduced defect lives in a component that survives the target architecture
  (incremental + bounded consolidation), so none is left to rot on migration grounds.
- P0 pair (B1, B2) costs a few hours and changes what the oracle *sees*; everything else
  is downstream or smaller.
- B6 is the cheapest fix with the largest hygiene payoff (it also stops the kit's own
  gate from writing to the operator's home on every run).
- Two of the loudest prior findings are not defects: prose quality (B26) and "review/final
  check are not commands" (ledger L-09).
- Three roadmap bugs are stale (B21) or already satisfied (FT190, FT165) — a reminder that
  the board needs the same "does the problem still exist" pass this triage applied.
