# Working-tree gate changes are defended by planted-reason proofs and a push-time pin

The gate may evolve in the same working tree as the code it grades. Each retained kit
fixture is defended by an ordinary mutation test. The test calls its exact registered owner,
requires the planted diagnostic, restores the subject, and requires that diagnostic to
disappear. Canary inventory validation establishes bindings only. Linked repos receive
that inventory validation and own planted-reason proof in their native tests.

The managed pre-push hook separately compares the committed gate tree with a
human-recorded local pin and blocks drift when a pin exists. These layers make lazy or
accidental weakening loud; resistance to an actor who can edit local hooks is outside the
threat model.
