# Working-tree gate changes are defended by planted-reason proofs

The gate can change in the same working tree as the code it grades. An ordinary
mutation test defends each retained kit fixture. The test calls its exact
registered owner, requires the planted diagnostic, restores the subject, and
requires that diagnostic to disappear. Canary inventory validation establishes
bindings only. Linked repos receive that inventory validation, and they own a
planted-reason proof in their native tests.

The reviewer owns the merge and reads every gate change, so that review is the
human check. These layers make lazy or accidental weakening loud; resistance to
an actor who can edit local hooks is outside the threat model.
