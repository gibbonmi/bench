# Independent test expectations preserve demonstrated omission oracles

An independently authored test expectation is distinct from duplicated implementation knowledge only when its independence is necessary for a named omission or mutation to make the gate red and that red is recorded and demonstrated. This exception keeps completeness oracles able to detect missing registrations; it applies only to the expectation-versus-implementation pair, while production policy, parsers, fixture harnesses, executable registries, and derived counts remain single-sourced.
