# Independent test expectations preserve demonstrated omission oracles

An independently authored test expectation is distinct from duplicated implementation knowledge only when two conditions hold. First, its independence must be necessary for a named omission or mutation to make the gate red. Second, that red must be recorded and demonstrated. This exception keeps completeness oracles able to detect missing registrations. It applies only to the expectation-versus-implementation pair. Production policy, parsers, fixture harnesses, executable registries, and derived counts remain single-sourced.
