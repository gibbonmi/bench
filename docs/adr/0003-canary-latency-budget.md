# The canary keeps the gate's critical path; latency is bought only with semantics-neutral fixes

The canary sweep — the gate running itself against every known-broken fixture — is the most expensive gate phase and sets the gate's wall clock. A strict budget ("the meta-check must cost no more than the slowest real check") was considered and rejected: reaching it requires cuts to oracle semantics, and every candidate cut trades away some of the loudness the canary exists to provide. The accepted posture is lenient: the sweep runs every fixture's full inner gate, unconditionally, and its cost is managed only by fixes that leave the oracle's verdicts untouched — the current wall (~26 seconds, roughly the same as the conformance phase) is accepted as the price of an unweakened meta-check.

If the sweep's wall creeps enough to hurt again, the first resort is decided in advance: **scope each fixture's inner gate to the phase family its expectation targets.** That cut fails safe — a check that migrates phases makes its fixture report "did not bite" loudly rather than pass silently. The other candidates stay rejected until the reviewer reopens them: skipping the sweep on a "canary-relevant inputs unchanged" key fails dangerous (a missed key input yields exactly the silently vacuous canary the sweep exists to catch), and batching fixtures into shared inner runs allows cross-contamination in both directions (one fixture's breakage masking or satisfying another's expectation).

## Consequences

- Inner-gate latency is a canary multiplier: one second added to the inner gate costs roughly a fixture-count's worth of seconds per sweep, so tests that can wait on wall-clock deadlines must fail fast on evidence (a child that has exited can never act later) instead of sleeping out their timeout against broken fixture trees.
- One residual is accepted: the concurrent-acquire test's wall-clock timeout branch is its backstop for a live-but-stuck child, and no fixture or test drives that schedule — a regression confined to that branch would land green. The reviewer accepted this at spec sign-off; the cheap close, if ever wanted, is a driver that records once and then hangs.
