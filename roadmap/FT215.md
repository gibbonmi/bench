**FT215 (MEDIUM) — no changed-package-scoped gate path; every diff pays the full fixed-cost floor.**

Add a scoped `bench gate` path that runs only the packages a diff touches (plus
their dependents) instead of the whole suite. This stops a one-file change from
paying the fixed per-package floor measured below. Decide whether the full
suite stays the pre-commit default and scoped becomes an opt-in iteration
mode, or the reverse. The same decision prices a capture-only fast lane.
Commits touching only `capture/` and `specs/*.md` cannot break the Go phases,
yet each pays the full floor today. Entry: `/bench-shape-idea`.

Two more faces price the same decision. `bench commit` runs gofmt on the
changed Go files before the full gate, so a mechanical formatting repair does
not cost a second full run. And a staged spec or ticket commit runs the
focused coverage and preflight checks, while one final composed landing owns
the full-project gate. The landing reuses evidence when the prospective tree
and the runner identity are exact.

A third face: `bench commit` runs the focused prose check on the changed
Markdown before the full gate, so a bound violation costs seconds and not a
full red run.

Two command projections share this owner. `bench test --package <path> --run
<pattern>` reports only the focused failure set. `bench gate --check <name>`
runs one named conformance check with the gate-owned environment. Shape these
with the scoped gate so the kit does not grow competing iteration paths.
