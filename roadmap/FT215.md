**FT215 (MEDIUM) — `bench commit` uses a path-aware fast lane before the full gate.**

`bench gate` remains the whole-project oracle. `bench commit` composes its
changed paths before it selects the fast lane. The composed input expands named
directories and represents a rename as a deletion and an addition.

- Go source selects gofmt, vet, and build.
- Go metadata or a named embed input selects vet and build.
- Markdown or prose policy selects prose.
- A known document class can select its existing focused validator.
- Mixed known paths select the union of their checks.
- An unknown or symlink path selects the complete current lane.

The attribution owner still refuses special and unreadable paths before the
lane selects checks.

A lane check carries the name of a gate check only when it runs the same bound over
the same bytes. The spec names each lane check's gate counterpart and the mutation
that reds both.
