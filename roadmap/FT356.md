**FT356 (HIGH) — the worktree joins seam set keeps only the seams that make a failure reproducible.**

The worktree joins seam set has 28 function-typed seams. Each seam has one production
adapter, and 15 of 30 fields are replaced at exactly one test site. Time and home arrive
by several routes. The parallel census refuses package variables, so this seam set
exists to keep the package parallel-eligible.

Keep parallel eligibility. Keep only the seams that make an unreproducible failure
reproducible, such as the merge reconcile, the cleanup boundary, and the build. Each
verb reads the kit root, the home, and the clock once. The other seams use real git and
temp-directory fixtures. The parallel census then shrinks with the seam set.

The worktree tests hold 24,581 lines, about twice the source. They restate how to call
a verb, build its fixture, and read its answer. The tree has 195 copies of the output
buffers, seven run-wrapper shapes, 20 fixture-tuple shapes, and five fingerprint
extractors. `axitest.DecodeDocument` exists, and few files use it.

One runner returns a result value for each verb: the exit code, the rows read through
`axitest`, and the fingerprint. Named fixture values with fields replace positional
tuples in one helper file. The runner's fixtures follow the reduced seam set, so one
shaping pass decides both.

This is the survey's top recommendation. It drives the size of the parallel census and
the test-harness sprawl.
