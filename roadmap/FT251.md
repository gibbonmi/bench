**FT251 (MEDIUM) — a killed landing orphans the private prospective tree and its gate binary.**

The landing builds a private prospective tree and a gate binary, and it
removes both through a deferred cleanup. A deferred cleanup cannot run under
SIGKILL, so a killed landing leaves the tree and the binary behind, and no
verb sweeps them. The fix needs an owning-PID convention: each private tree
records its owner, and a sweep removes a tree whose owner is gone. This is a
new seam with its own design, so it is not a light-path ticket.
