**FT235 (MEDIUM) — a pool directory's name says what the worktree is for.**
`worktree create` names a pool directory `<ownerID>-<assignmentID>`, so `ls` of a
pool shows two opaque hashes and nothing about purpose. The name carries the
label's slug instead, since the owner id already lives in the marker.

Needs a spec: the pool holds mixed-shape names for worktrees that already exist,
and every reader that parses a directory name rather than the marker or the
assignment record has to be audited — the `lifecycle.go` sweep and reconcile,
clean, and reauthorize among them.
