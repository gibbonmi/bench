**FT290 (LOW) — `bench test` projects a check's fixture family, a full failure body, and a no-match attribution.**

Projection faces on one verb. `bench test --check <name> --fixtures` shows the
canary family a check owns. A charge author then reads that family from the CLI
instead of the fixture-bite test.

The `--full` flag shipped. The residual is the row shape: the report carries one
row for each failing test, so a multi-line failure body still collapses.
`bench test --check` prints one failures row for each diagnostic. When a check
name is unknown, the refusal names the binary it consulted. A stale `dist/bench`
otherwise lists a stale check set with no attribution.

When `bench test --run` matches no test, the verb attributes a compile error
directly. FT277 owns only the explanation for a widened `--changed` set.
