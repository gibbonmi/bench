**FT164 (MEDIUM) — repair-lane charges, and a done-claim that resolves its named owners.**

The done-claim verification core landed in `craft-delegate`. Two rules remain
unbuilt. A repair charge has no named template. Each one is improvised. It
should name its base commit, its ownership fence, and its effort. It should
also name the focused suite that must go green, and the independent probe
that proves the fix bites.

And a
done-claim must resolve every Red-mutation owner it names to a real artifact in
the tree. An owner that resolves to nothing is an unverified claim wearing the
shape of a result. Accepted review findings stay attached to their original
ticket when attribution is clear. An umbrella repair ticket is reserved for a
genuinely shared owner, not used as a ledger for unrelated slices.

When the installed lane cannot commit its own fix, the repair charge runs the
same commit core from the candidate tree. It still grades the composed snapshot
and requires the sanctioned rebuild after landing.
