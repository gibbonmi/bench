**FT274 (MEDIUM) — Bench traces its own seams with OpenTelemetry and records the FT231 measures.**

Bench instruments its own seams with OpenTelemetry spans and metrics. The
instrumented seams are the gate phases and lanes, `bench commit`, the landing's
composition and publication, and the worktree verbs. The harness hook events
Bench already receives join them. Each span names the seam, the subject, and the outcome.
Each span carries the FT231 measures the record can own: elapsed time, gate
iteration, phase exit, census raw-call count, and write-set size.

Harness-owned measures join as attributes only when the wired hook layer
supplies them. These are tokens, tool calls, Read paths, and turns. The harness
capability record declares which harness supplies which measure. A measure with
no source stays absent.

The reviewer decided three points on 2026-08-29. The exporter writes OTLP-JSON
lines to a local file under `BENCH_HOME`. No OTLP client, gRPC, or protobuf
module enters the binary, and a collector's file receiver ingests the file. The
span processor writes a record at span start and at span end, so an interrupted
run keeps its started phase. The spec proves this with one test: a gate killed
mid-phase still shows the started phase in the record. If that test cannot pass,
FT71 stays a separate ledger and its recommended dependency on this row is
withdrawn.

The first slice yields timing and outcome data, not token data. Tokens, turns,
and files read need a transcript reader, which FT204 owns, and a judgment
measure enters only through an event the coordinator emits. The dependency is
`go.opentelemetry.io/otel` and its SDK from the open-telemetry organization
under the Apache-2.0 license, admitted under the dependency standard on the
reviewer's direction.

FT231 reads this record as its instrumentation half. FT232's advisory, FT204's
query, FT241's retained evidence, and the scorecards in
`capture/agent-performance/` read the same record. This row is FT275 applied to
the kit itself. Source: the reviewer's 2026-08-29 BAML design review and
OpenTelemetry direction (review prompt only).
