**FT158 (MEDIUM) — make cross-harness falsification standing for kit-guidance diffs.**

The falsification pass survives in guidance only as an offer. Implementation
names it as one of two passes that are "never silently applied." `craft-line`
prices it. For a diff that changes kit guidance, it becomes standing rather than
offered, with each finding taking an explicit accept, merge, or dismiss
disposition. A guidance change is exactly the class whose defects no gate check
can see. So the one pass that reads it from another harness's vantage should not
be optional.
