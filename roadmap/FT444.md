**FT444 (LOW) — each retro improvement item names its fix lever.**

An implementation retro lists improvement items with a `Feeds:` line, but no item names
the kind of fix that it asks for. Each item names one fix lever: `check`, `review-rule`,
`pointer`, or `remove`. A form line in the retro scaffold turns the grading on, and an
older retro stays exempt.
