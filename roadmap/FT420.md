**FT420 (HIGH) — the review record and the author charge support the concurrent chunks of a delegated full run.**

Since b20d401fb, an approved `--full` run takes `--delegate` by default with an author limit
of 3, and chunks author concurrently when the prerequisite and no-overlap rules allow it.
FT449 ran the first concurrent chunks, NG-C4 to NG-C6, and showed what the default still
needs.

The review record walks chunk entries serially. A record model with sibling chunks that
share one predecessor, or a verb that orders entries by plan and chains bases, lets
concurrent chunks run with no hand repair. The implement-spec guidance holds the interim rules until then. A
concurrent dispatch into one Go package names the owner of each new shared helper. A plan
commit that raises the author limit records each freed dependency. FT455 owns the test-only
confirmation under sibling chunks, and FT381 holds the risk classes and the repair routing.
A second face lets an author draft early against a predecessor's declared seam.

A delegated run dispatches every eligible ticket up to the author limit, at ticket-dependency granularity. The reviewer decided on 2026-10-29 that this dispatch is an obligation, and that each concurrent chunk gets its own worktree. Today `.bench/BENCH.md` permits that concurrency but does not require it.
