**FT420 (HIGH, decision required) — a spec-backed build authors independent chunks concurrently by default.**

A spec-backed build authors its tickets one at a time with an author limit of 1, unless the
reviewer asks for `--delegate`. Chunks with no shared prerequisite and no write overlap
then wait for each other. The existing prerequisite and no-overlap rules already tell when
two chunks can run together.

The reviewer decides whether the concurrent mode becomes the default for a spec-backed
build, and whether the orchestrator chooses the concurrent chunks. This decision changes the
operating-guide rule that a full run delegates only on the reviewer's request. FT381 holds
the risk classes and the repair routing that a delegated run needs first. A second face lets
an author draft early against a predecessor's declared seam.
