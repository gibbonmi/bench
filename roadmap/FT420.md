**FT420 (HIGH) — a spec-backed build authors independent chunks concurrently by default.**

A spec-backed build authors its tickets one at a time with an author limit of 1, unless the
reviewer asks for `--delegate`. Chunks with no shared prerequisite and no write overlap
then wait for each other. The existing prerequisite and no-overlap rules already tell when
two chunks can run together.

On 2026-10-13 the reviewer made the concurrent mode the default for a spec-backed build.
The orchestrator runs chunks together when the prerequisite and no-overlap rules allow it.
This decision replaces the operating-guide rule that a full run delegates only on the
reviewer's request. FT381 holds the risk classes and the repair routing that the default
needs first. A second face lets an author draft early against a predecessor's declared seam.
