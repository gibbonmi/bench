**FT366 (MEDIUM) — a PreToolUse guard refuses a pathless `rg` call through the shared command projection.**

The guards share one `shellcommand` command projection and one envelope reader. The guard
scan is one synchronous loop. The degraded rim refuses malformed input with parse-repair
advice. One face remains.

A new PreToolUse guard uses the shared projection to inspect `rg` calls.
It requires a path operand unless a pipe in the same command supplies stdin.
It recognizes options that consume a value and permits a call when that operand analysis is uncertain.
This new guard's uncertainty policy does not weaken the existing dangerous-command guards.
The guard names command substitution in its refusal, and it treats the quoted and unquoted
forms the same way. Like every guard, it is an honest-mistake check, not an
evasion-resistant shell interpreter, and its projection never executes the command.
