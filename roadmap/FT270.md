**FT270 (LOW) — `bench test` names its checks, prints every finding, and runs the system suite.**

`bench test --help` lists the named-check inventory. `bench test --check` prints
every finding instead of the first 141 bytes. `bench test --check system` runs the system
suite with `BENCH_KIT` and `BENCH_RUN_BINARY` set from a fresh build, so no
`--system` flag is wanted. A hand run thus needs no hand-built binary and no gate
wrapper environment.

`bench test --check <unknown>` names the unknown check and lists the check
inventory, because the bare usage line reads as a missing flag.

When `TestRootConformance` skips, `bench test --package ./internal/conformance`
reports a package pass and names `bench test --check <name>` as the graded-root
path, so the package pass never reads as a root green.

`bench test --check prose` provides a named route to the prose lane.

`bench gate-prose --help` exits zero on stdout. `bench gate-prose` prints the
offending sentence with its line number, so a coordinator fixes prose without a
second read of the file.
