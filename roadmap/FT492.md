**FT492 (LOW, parked pending a repro) — the live branch of the nested sweep validates a store record before it deletes the store.**

The live-generation branch of `discardNested` decodes the resource record and deletes the store when the resource path is inside the removed directory and absent. It applies no validity check. The retired branch applies the strict validity check of the record owner first. Only a damaged or forged record in the private store root reaches this gap. Graduation trigger: a test-first red in which a record that names a path outside the removed directory, such as `<dir>/../sibling`, has its store deleted, and a reviewer decision that a forged record in the private store root is inside the threat model.
