**FT314 (MEDIUM, decision required) — an unchanged landing composition reuses gate evidence only under a complete authorization key.**

The landing gate already reuses evidence during a retry when the graded tree
and baseline runner stay unchanged. A cross-run reuse would skip a duplicate
full gate for an unchanged composition.

The reviewer decides whether that reuse is safe. The authorization key must
bind the composed tree, gate version, toolchain, and capability posture. A
change to any key member runs the full gate.

The design must preserve the gate as the oracle. It must not treat an old
receipt as authority for a different execution environment.
