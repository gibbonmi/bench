although the spec holds each one. `bench preflight build` has no row for drift, for a
cited symbol, or for a cited test.

coverage map. The build preflight gains three rows:

- A drift row lists each fenced path that changed from the spec's pinned commit to the
  source tip.
- A cited-symbol row reports each symbol of the cited-symbols table that does not
  resolve.
- A cited-test row reports each existing seam test that is absent and each planned test
  that exists.

When these rows are green and the drift row is empty, `/bench-implement-spec` dispatches
no staleness pass.
