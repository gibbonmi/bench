**FT409 (MEDIUM) — `bench test` reports the slowest tests and warns when a package nears the go test timeout.**

No Bench output shows the cost of a test. A ticket can double a package's run time, and the
first signal is a gate that times out. `bench test` reports the slowest tests of each
package and the package elapsed time. It warns when a package nears the go test timeout
that the gate uses.

This signal makes the test-cost contract in FT369 checkable.
