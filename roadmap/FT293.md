**FT293 (HIGH) — preflight closes each ticket's complete ownership fence.**

The preflight proposes canonical ownership closure for fixtures, registries, anchors,
callers, and owner files. It checks sizing, symbol, rule, and recorded-evidence premises
before a charge, and `--breakdown` projects the closure of an unfinished graph. The
residual work below is not in the tree.

**Five more closure members.** A ticket that adds a top-level test names the serial-ceiling
pin of its package. A ticket that changes a refusal or a printed sentence names each test
that pins the old output exactly. A ticket that makes a test helper package import
production code names each internal test that imports that helper. A ticket names the
source file of each symbol that a closed decision or a headroom route moves. A ticket that
grows a file near its line budget, or adds tests to a test file near the structure cap,
names a headroom file before dispatch.

**The slicing-time projection.** `--propose-writes` reports one ticket's closure files
while `rows-owned` or the completion plan is red, and it answers every ticket in one call
when no `--ticket` is given. It adds each anchor registry file, and its test twin, that
pins a needle in a guidance file on a ticket's `Writes:` line. `--plan-only` reads an
uncommitted completion plan. A preflight with many closure reds spills its detail and still
renders a verdict.
