**FT377 (MEDIUM, decision required) — the package-core check grades `npm pack` only on the declared Node and npm floor.**

`package.json` declares `node >=24`. The package-core check runs
`npm pack --dry-run --ignore-scripts` with no floor check. On a host whose shell selects
Node 18 and npm 9, that command runs `prepare` anyway. It rewrites the live binary, its
seal, and the broker manifest, and the gate then refuses the checkout changes.

Decide whether the check refuses a toolchain below the floor or skips it by capability.
Also decide whether session startup reports the selected Node and npm paths when the
host has more than one installed toolchain.
