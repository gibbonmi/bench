**FT307 (MEDIUM, decision required) — `bench structure` diff queries read NUL-framed names and grade the working tree.**

`bench structure --since` reads a newline-framed `git diff --name-only`. A source
name with a byte above ASCII arrives C-quoted, and the extension filter drops it.
The growth mode uses NUL framing, and `--since` can adopt the same query. The
change is behavioral for non-ASCII names.

`bench structure --since` diffs `base..HEAD` and never sees uncommitted work.
The growth mode already grades the working tree against the base. The reviewer
decides whether `--since` adopts the growth query, or reports that the tree is
dirty.

`bench structure --growth` names the grown file but not the package headroom.
The whole-tree census exits 1 when a delegate needs only its own diff's growth.
A `--package <dir>` headroom view is a candidate face for the same query.
