**FT442 (LOW) — a build widens each consumer file of a touched declaration before dispatch.**

Review scope caused about 41 percent of the October `Writes:` widenings. A ticket names
the file that it changes but not the consumer files of a declaration that it touches or
deletes. `bench consumers --changed` lists those consumers, and `bench spec widen` adds
them, but no step runs the pair before dispatch.

A class of widening that a check can name stops adding slicing prose. The uncovered
shapes are decision-map citations, help-row allowlists, registry-order tests, and stale
comments. The FT362 build added three more shapes: a helper that an earlier ticket moved or
added, a census pin file of a package that gains top-level tests, and the conformance
registry, check-binding, and lane-table paths of a new live-tree audit. The FT445 build added four more shapes: the refusal-route
registry of a new refusal, each test that pins a shared fixture's re-retain behavior, the
owner file of a fact that a review-found one-source repair collapses, and `CHANGELOG.md` on
a user-visible ticket. The first step is the reclassification of the widenings in the builds since
FT293, which is runnable now.

The FT314 and FT450 builds added sixteen more widenings. In FT450, 7 of 13 gave a second
caller a shared helper or fixture, which `bench consumers --changed` cannot list. Two more
shapes join the list: each test, staged-spec coverage citation, and fixture that pins a
name, key, or refusal that the ticket renames, re-keys, or reverses; and a test that reads
an unexported gate fact. FT455 owns the confirmation and charge cost that a widening adds.
