**FT387 (MEDIUM) — a verified harness path preserves complete tool output before it returns a bounded replacement.**

A wrapper can show an oversized result after an upstream layer already dropped producer
bytes. A hook with the wrong replacement form can also hide a failure status.

Each installed harness path is verified before it can replace a result. The path keeps the
complete result first, then returns diagnostics, status, the true size, and an exact detail
route. An unsupported path keeps the original result and reports the limit.

The staged spec is `specs/session-context-overflow/spec.md`.
