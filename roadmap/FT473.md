**FT473 (LOW, decision required) — the staleness pass can be omitted for an audit whose only diagnostic is metadata and whose drift list is empty.**

The staleness pass allows omission only on a complete audit. An incomplete audit whose only diagnostic is metadata and whose drift list is empty still dispatches the pass, which then returns current. The reviewer decides whether the orchestrator can omit it.
