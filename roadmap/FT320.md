**FT320 (MEDIUM) — the `craft-review` finding discipline states three reader rules and one return rule.**

The finding discipline states what a finding carries. Three reader rules and one return
rule are missing, and each gap produced a wrong finding, a red gate, or a partial result.
One kit edit adds these rules:

- A Coverage finding describes the tree before the probes of the axis, never behavior that those probes added.
- A review of gate-anchored prose names the anchor state of each sentence that it proposes to change.
- An axis reads the seam cell of a row before it judges a review-owned row unmet.
- An axis return lists the evidence cursors that it fetched, so the coordinator finds a partial retrieval before it accepts the result.
