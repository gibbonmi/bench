**FT320 (MEDIUM) — the `craft-review` finding discipline states three reader rules.**

each gap produced a wrong finding or a red gate. One kit edit adds these rules:

- A Coverage finding describes the tree before the probes of the axis, never behavior that those probes added.
- A review of gate-anchored prose names the anchor state of each sentence that it proposes to change.
- An axis reads the seam cell of a row before it judges a review-owned row unmet.
