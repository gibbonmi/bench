A drain records each settled row decision in its `roadmap/FT<n>.md`. When a committed
outcome pins the row as a source, `bench commit` refuses the row edit. `bench commitment plan`
also refuses an input that carries the edited row identity, because it reads the committed
row. The decision can then go only into an outcome criterion, and the row file keeps its old
decision state.

Decide the route. One option is that a plan input carries the new row identity together with
the row edit, so one approved plan and one commit record the decision. The other option is
that the drain guidance names the outcome criterion as the record, and the row edit lands
with the outcome.
