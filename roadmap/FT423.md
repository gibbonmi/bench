**FT423 (LOW, parked pending a repro) — `bench record verification` refuses a probe entry that the checkpoint would refuse.**

The manual flag path of `bench record verification` writes a probe entry with no check that
its exit code agrees with its probe outcome. The `--probe-result` import and the chunk
checkpoint do check it, so a wrong entry fails only at the checkpoint. The writer and the
checkpoint share one predicate.

Graduate when `bench record verification … --probe-outcome bit --probe-exit-code 0` exits 0
and the chunk checkpoint later refuses that entry. FT318 owns the fix on graduation.
