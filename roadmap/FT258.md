**FT258 (HIGH, decision required) — `bench commit` derives a complete change set from the checkout.**

A hand-written commit path list omitted changed files and paid a red gate.
Decide how the command obtains its candidate set. It can derive the set from
checkout status and check it against the named ownership fence. Alternatively,
the caller continues to name every path. The result leaves unnamed and
unauthorized files unchanged, and it does not turn status discovery into
mutation authority.

The candidate forms are `bench commit --changed`, `--dry-run --changed`, and
`--ticket <file>`. `--changed` composes the worktree's dirty set.
`--dry-run` shipped as a lane rehearsal on named paths; `--dry-run --changed` would print the derived set and write no commit. `--ticket <file>`
composes the `Ticket:` trailer.

The merge-parent rule shipped at `85f2b05c` (commit-merge-parent). During a pending
merge, `bench commit` records each merge head as a parent. It refuses a name set that
omits a merged path, and it ends the merge through Git. The candidate-set forms and their
derivation decision stay open on this row.
