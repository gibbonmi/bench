**FT397 (LOW, decision required) — a phase close names the parallel tracks that write disjoint files and cross disjoint seams.**

When a phase closes or the router names the next action, the guidance can name work that
runs at the same time. Candidates are an unstarted spec stage, a drain light-path fix, or
an outcome that a parallel grant admits. A track qualifies only when its expected
`Writes:` set and its seams do not overlap the active work. The recommendation states the
overlap that rules a track out.

The reviewer decides how this fits the rule of one active commitment. A spec stage and a
light-path fix need no commitment. An outcome that a parallel grant admits does.
