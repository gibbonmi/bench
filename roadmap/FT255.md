**FT255 (MEDIUM, decision required) — concurrent tests share one explicit machine budget.**

One pool under `BENCH_HOME` owns N test slots for gate phases, worktree commits,
and focused delegate runs. A run waits when no slot is free. The slots it holds
derive both Go package and test parallelism, so concurrent worktrees cannot
oversubscribe the host.

Shape a static first step with the pool. Gate, commit, and landing accept one
shared setting, with a headless environment form and the flag taking priority.
A quiet measurement found four matched the uncapped wall while two added about 20
seconds. The reviewer decided on 2026-10-10 that the default is two, and that the flag
and the headless environment form still override the pool default. The shape session
takes these two decisions as closed inputs.

Until the pool exists, a fold or a whole-tree gate waits for every live
delegate test run. An `infrastructure` refusal inside a landing test is a
load signal first, proved by one isolated run before a retry.

Include outer gate-phase scheduling in the shared machine budget.
Measure contention across phases before choosing a width cap.
