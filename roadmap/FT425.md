**FT425 (LOW) — a Bench write verb prints the tree state after it runs.**

The tree header of a Bench response shows the state before the command. After a write
verb, an agent therefore runs `git status` to learn the head and the dirty paths. Each
write verb prints one line after it runs: the head and a bounded list of dirty paths.

The line reuses the bound and the spill rule of the existing tree header. It adds no second
renderer.
