**FT354 (MEDIUM, decision required) — Bench has one shell-quoting derivation.**

Two functions render a value as one POSIX shell token, and each doc says that it is the one
derivation. `axi.ShellQuote` prints a safe value bare and escapes a single quote as
`'"'"'`. `sanitize.ShellQuote` always quotes and escapes a single quote as `'\''`. About 20
call sites split between the two, and a worktree build refusal quotes its label through the
second. The decision names the surviving function and its bare-token rule. A merge changes
printed commands across the kit, so each changed command line needs a test update in the same
landing.
