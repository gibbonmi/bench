**FT354 (MEDIUM) — strict JSON and shell quoting each have one owner.**

Three functions render a value as one POSIX shell token: `axi.ShellQuote`,
`sanitize.ShellQuote`, and a private `shellQuote` in `internal/freshness`.
`axi.ShellQuote` prints a safe value bare and escapes a single quote as `'"'"'`. The other
two always quote and escape a single quote as `'\''`. About 20 call sites split between
them, and a worktree build refusal quotes its label through `sanitize`. `sanitize.ShellQuote` survives
with its always-quoted contract. A merge changes printed commands across the
kit, so each changed command line needs a test update in the same landing.

One more primitive has several owners. A duplicate-key JSON read lives in `jsonfile`, the
gate verdict store, `reviewrecord`, and `releaseevidence`. `jsonfile` owns the strict read,
and the gate keeps its sentinel errors through it. This part needs no decision, and a spec
can take it after the quoting decision.

The staged specs are `strict-json-ownership` and `shell-argument-ownership`. Each spec names
the outcomes that stay open.
