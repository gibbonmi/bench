**FT318 (MEDIUM, decision required) — the review record has a native writer.**

Each coordinator session wrote the review record fence with a script: the chunk entry,
the round entry, and the completion entry. The review phase names the pickup payload,
but no verb writes it. FT254 rules that a raw-call count alone selects no new command,
so this row needs a decision.

Decide whether a `bench review record` verb earns a seam. The alternative is a smaller
payload that the edit tools write without a script.

**The record content (folded from FT313).** The record uses stable evidence identifiers
and gives each missing row one reason. It stores compact event summaries with source
digests, so a consumer can reconstruct the record and validate the same evidence.
