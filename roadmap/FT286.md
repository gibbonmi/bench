**FT286 (MEDIUM) — the prose six-sentence bound survives a label-shaped prose line.**

`isLabelLine` in internal/prose/parse.go (line ~330) treats a line as a template
label when its first colon follows one to four words. The caller at line ~257
then starts a new paragraph. The comment at lines ~259-260 says a label line is
a template field with no sentence terminator. The code never tests the rest of
the line for a terminator. An ordinary prose sentence such as `Run the real
path: ...` therefore resets the paragraph, and the six-sentence bound does not
bite.

Candidate rule: a label line must carry no sentence terminator. The reviewer
decides that rule, because a tightened check can red current guidance files.
