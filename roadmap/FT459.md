**FT459 (LOW) — a build's docs ticket receives each spec-versus-code divergence that the build settled.**

A build settles some spec-versus-code divergences during its chunks. The docs ticket does
not receive them, so the spec prose and the shipped code disagree at the docs review. The
kit edit tells the orchestrator to charge the docs ticket with each settled divergence and
to correct the spec prose before the docs review.
