**FT317 (MEDIUM, decision required) — a capability-blocked acceptance row has one decided value at the completion checkpoint.**

An acceptance row can need evidence that the build host cannot produce. Two rows of
`bounded-charge-evidence` had this shape: CE94 needs a privileged device, and CE117
needs macOS storage evidence. Each row was reconciled by a reviewer decision while its
evidence stayed unrun. The retirement removed the review pickup that held both notes.

Decide at spec approval how such a row reconciles. The decision names the value that the
completion checkpoint records for the row, and it names the owner of the open
evidence.
