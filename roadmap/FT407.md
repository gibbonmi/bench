**FT407 (LOW) — the adoption transaction seam has a removal fault point.**

The adoption transaction fault seam fires only on renames. So no test can interrupt an
Unlink between its file removals and its final manifest write. FT217 amended its row ALC34
because of this gap, and its fences excluded the transaction adapter.

The seam gains a fault point at a removal, and one Unlink test interrupts at that point and
proves that `Undo` restores every destination.
