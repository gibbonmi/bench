**FT226 (HIGH) — kit tests stop writing into the operator's real `BENCH_HOME`.**
`internal/worktree` reauthorize fixtures create pool worktrees under the ambient
`BENCH_HOME` and never remove them, so an ordinary gate run leaks pool
directories into the operator's own machine. Fixtures bind a temporary
`BENCH_HOME` for the duration of the test and leave the ambient pool untouched;
a test that writes outside its temporary root is the gate's own red. The
existing orphaned directories are swept once as part of the same build.

Occurrence: 2026-08 capability audit (ledger L-06) — 759 orphaned `001-*` pool directories, 41 MB, in the operator's `~/.bench/worktrees`, roughly ten added per gate run.
Occurrence: 2026-08 capability audit — the same leak under a subject-pointing `BENCH_HOME` reappeared as external subject pollution.
