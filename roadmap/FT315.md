**FT315 (MEDIUM) — a landing supplies the declared `BENCH_HOME` itself, and `bench doctor` reports a missing declared gate input.**

`.bench/gate-inputs.json` declares `BENCH_HOME`. The shell wrapper derives it,
but `bench worktree land` reads it from the calling shell. When that shell does
not export it, a green gate refuses the landing as infrastructure. The refusal
does not name the variable, and `bench doctor` reports every check as ok.

The landing derives `BENCH_HOME` the way the wrapper does, or it refuses with
the variable name. `bench doctor` reports each declared gate input that the
current environment cannot supply. Start with `/bench-debug`, and build a
red-capable loop through `bench worktree land` before the fix. FT287 keeps the
refusal-clarity evidence, and FT254 records the related broker environment
drop.
