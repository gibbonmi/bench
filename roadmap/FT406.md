**FT406 (MEDIUM) — a commit in a build worktree leaves no stale `dist/bench` for the next preflight or `--in` verb.**

A ticket commit that changes a Go build input leaves the worktree binary at the previous
source. The next `binary-seal` row then reds, and the author or the orchestrator runs
`bench worktree build` by hand. `docs/known-issues.md` holds the workaround, and this row
is its retire owner.

A Markdown-only commit also makes `bench test --in` and `bench anchors --in` refuse with a build mismatch. The reviewer decided on 2026-10-10 that `bench commit` rebuilds the worktree binary when
the commit changes a Go build input. The build key ignores a Markdown-only change. FT344 owns the remedy wording, and FT398 owns a test that reads a stale binary.
