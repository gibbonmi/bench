**FT406 (MEDIUM, decision required) — a Go commit in a build worktree leaves no stale `dist/bench` for the next preflight.**

A ticket commit that changes a Go build input leaves the worktree binary at the previous
source. The next `binary-seal` row then reds, and the author or the orchestrator runs
`bench worktree build` by hand. `docs/known-issues.md` holds the workaround with no retire
owner.

The reviewer decides where the rebuild lives. Either `bench commit` rebuilds the worktree
binary when the commit changes a Go build input, or the preflight remedy names the rebuild
and runs it. FT344 owns the remedy wording, and FT398 owns a test that reads a stale binary.
