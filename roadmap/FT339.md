**FT339 (LOW) — `bench anchors` reads the registry of the named worktree and takes a directory.**

`bench anchors` reads the registry that is compiled into the installed binary. A delegate in a
worktree that adds or changes anchor rows therefore reads a stale registry. When `bench
worktree exec` runs the verb, it reads the registry of that worktree. The verb also takes a
directory, so one call grades every guidance file below it.
