binary that traces a seam writes real records under `~/.bench/otel`. The FT303
CLI assessment found 25,015 record directories and 309 MB there since
2026-08-30, all under the service name `authorization.test`.

Decide the test-home posture. Either each test harness sets `BENCH_HOME` to a
temporary directory with `t.Setenv`, or the record writer refuses to write
while the binary runs under `go test`. The recommended option is the writer
refusal, because one seam covers every present and future test binary, and a
per-harness `t.Setenv` misses the next harness.
