**FT344 (MEDIUM) — every rebuild remedy for a pool worktree names `bench worktree build` from one owner.**

The freshness rebuild action builds each rebuild remedy as a `cd` into the root and a
run of the build script. The hooks refuse a `cd` into the pool path, so a remedy for a
pool worktree cannot run. The binary-seal row of the build preflight now names `bench
worktree build`. The live-binary check, the command entry, and the landing still print
the `cd` form. The rebuild owner cannot tell a pool root from the primary checkout,
so the fix needs a root-kind seam at that owner. Then each caller reads the remedy form
from the owner.
