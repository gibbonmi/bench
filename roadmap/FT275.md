**FT275 (MEDIUM) — code built under Bench traces its declared seams with OpenTelemetry.**

A spec declares its seams, and the build places one span at each seam's entry
point. The entry point is the exported entry the seam names on the provider
side, not each consumer's call site. One span covers one seam entry, not each
inner call. The span's attributes carry the seam name and the subject id, and
never a payload. `craft-seams` owns the placement rule, and `craft-spec` owns the
coverage row: each declared seam row names its span. A seam without a span is a
coverage gap the review grades.

The project profile declares tracing conformance the way it declares AXI
conformance, and a project without the declaration is exempt. The exporter is
the project's own choice, and the kit requires only the span at the seam. Bench
is the first conforming project through the shipped OpenTelemetry record.

The spec decides the mechanical check up front. For Go, a `go/ast` check asserts
that the seam's symbol body starts a span. A language without such a check keeps
the rule as a review finding. Source: the reviewer's 2026-08-29 BAML design
review and OpenTelemetry direction (review prompt only).
