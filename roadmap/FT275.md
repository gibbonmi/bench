**FT275 (MEDIUM) — code built under Bench traces its declared seams with OpenTelemetry.**

A spec declares its seams, and the build places one span at each seam's entry
point. The entry point is the import point where a consumer composes the
module. The span's attributes name the seam and its subject. `craft-seams` owns
the placement rule, and `craft-spec` owns the coverage row: each declared seam
row names its span. A seam without a span is a coverage gap the review grades.

The project profile declares tracing conformance the way it declares AXI
conformance, and a project without the declaration is exempt. The exporter is
the project's own choice, and the kit requires only the span at the seam.
Whether a project gate can assert that a declared seam's symbol starts a span
is a spec decision. Bench is the first conforming project through FT274.
Source: the reviewer's 2026-08-29 BAML design review and OpenTelemetry
direction (review prompt only).
