**FT455 (MEDIUM, decision required) — a plan-only or sibling commit keeps the test-only confirmation route, and a fence-only widening keeps the author's charge.**

`bench record confirmation` takes the test-only route only when the repair delta holds test
paths. A plan commit that widens a ticket's `Writes:` line puts the ticket file in the
delta, and so does a sibling chunk's commit on a shared integration branch. Each one turns a
test-only repair into a three-axis confirming round.

`bench preflight build --charge` refuses a dirty tree and regenerates over untracked paths.
A widening that arrives while an author's diff is dirty therefore leaves the author on its
earlier charge.

The reviewer decided on 2026-10-27 that the test-only predicate classes ticket `Writes:`
lines, the plan fence, and a sibling chunk's paths as plan paths, so these paths keep the
test-only route. The reviewer still decides whether `--charge` accepts dirty paths inside
the ticket's `Writes:` line, or whether a fence-only plan commit needs no regeneration.
