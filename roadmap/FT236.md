**FT236 (LOW) — `craft-review` visit: what a string expectation proves, and where an axis under-reads.**
One kit edit under `craft-synthesis` over a single owner surface.

When the production artifact is a generated script, an independently authored
string expectation is the mutation catch, not a weaker stand-in for a behavioral
test: the literal it spells is exactly what a one-character change to the
generator breaks. A review axis that discounts such an expectation as
"string-literal only" files findings its own cited evidence already refutes, and
the coordinator pays a read to dismiss each one.

The citation standard also needs a location clause. An axis that cites a file
and line it did not re-read this pass produces a claim that looks checkable and
is not: the coordinator either re-derives the location or accepts an unverifiable
citation. A finding cites the line the axis read this pass, or cites the symbol
instead and leaves the location to the reader.

Occurrence: 2026-08-19 FT227 review — the Coverage axis proposed a `-d`-to-`-e` guard mutation as uncaught while the string expectation it had already read spelled `-d` verbatim, and the edge was a declared Won't handle.
Occurrence: 2026-08-20 land-executable-freshness review — two axes cited file line numbers that matched no rendering of the files, including a registry closure cited at line 94 that sits at 555, while every substantive claim held.
