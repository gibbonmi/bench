**FT343 (MEDIUM) — production test seams have one decided policy that the injected-port audit enforces.**

The tree holds production `Set*ForTest` hooks. Each hook is a package variable with
a setter, and the injected-port audit does not see that shape. So an author can add a
hook to avoid the audit. The decision states whether a production test hook is allowed.
The audit then enforces that answer, and each existing hook gets a registry row or is
retired.

The same decision covers two other production test seams. `otelrecord` branches on
`testing.Testing()`. `releasepreflight` and `releaseevidence` read four
`BENCH_PREFLIGHT_*` environment hooks. Tests set the REF and RACE hooks, and the native
release probe sets a phase override family, so the decision keeps their evidence.

The staged spec is `specs/production-test-seam-policy/spec.md`.
