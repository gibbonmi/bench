**FT482 (MEDIUM, decision required) — a cache release decides when a live, leaked, or dead protected user seals the generation of its HOME.**

Today one leaked descendant of a test run keeps its protected-user registration. The cache
holder's release then seals the resource generation, and every later `bench test` on that
HOME refuses with "the resource generation is sealed" until the descendant exits. A user
whose actor and process group are dead on the current boot still counts as live. The
policy crosses the `gocache` and protection seam, so it needs a decision and a spec.

The reviewer decides two terms. The first term is whether a release seals a generation that
still has a protected user. The second term is whether the protection owner treats a user as
released when its actor and its process group are dead on the current boot.
FT446 holds the retired-store residuals and does not own this policy.
