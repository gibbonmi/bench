**FT285 (LOW, decision required) — a wrapped decision-map Sources continuation that holds a colon gets the one-physical-line refusal.**

The decision-map parser in internal/maps splits a Sources continuation on its first colon. A wrapped continuation that holds a colon therefore reaches the unknown-field message, not the one-physical-line message. The spec that shipped the wrapped-field refusal defines wrapped as no separator, so a continuation whose field name holds a space is undecided. Decide whether such a continuation counts as wrapped. The recommendation is a field-name shape guard before the unknown-field branch. A name with a space then routes to the one-physical-line refusal.
