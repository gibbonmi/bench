**FT285 (LOW) — a wrapped decision-map Sources continuation that holds a colon gets the one-physical-line refusal.**

The decision-map parser in internal/maps splits a Sources continuation on its first colon. A wrapped continuation that holds a colon therefore reaches the unknown-field message, not the one-physical-line message. The spec that shipped the wrapped-field refusal defines wrapped as no separator, so a continuation whose field name holds a space was undecided.

Decided 2026-09-02. A continuation whose field name holds a space is wrapped. A field-name shape guard runs before the unknown-field branch and routes it to the one-physical-line refusal.
