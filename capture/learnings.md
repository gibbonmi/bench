# Learnings — usage journal

- 2026-08-20 — /bench-write-spec (land-spec-amendments): the review round found two blocking gaps. (1) The spec promised "source bytes win unconditionally" over the destination's spec, but the composition path refuses an overlapping two-sided spec edit as a merge conflict before the overwrite runs — the author verified the byte check and the transition but never traced the merge's conflict path. (2) The implicit own-folder authorization makes the ownership-fence document self-amendable in-range, an authorization-chain change the Bootstrap authority section did not name. Right behavior: when a spec promises "X wins unconditionally" over a path that rides through a merge, trace the merge's conflict behavior for a two-sided fixture before locking the row; and when a change widens what a reviewed artifact may authorize about itself, name the new trust edge in Bootstrap authority explicitly. Proposed rule change: none — craft-spec's rubric caught both; the miss was authoring depth, not a rule gap.
